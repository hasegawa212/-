# COMPLIANCE

> 本書は実装上の想定であり法的助言ではない。〔要法務確認〕項目は運用開始前に専門家確認が必要。

## 適用法令の想定

対象は不動産（投資用・居住用）の電話勧誘。**宅地建物取引業者の取引は特定商取引法の適用除外**（特商法26条）となる一方、
**宅地建物取引業法施行規則 16条の11**（宅建業法47条の2第3項の委任）が勧誘時の禁止行為を定めている。〔要法務確認〕

| 規制（要旨）                                                                             | システム上の担保                                                                                                                             |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 勧誘に先立ち、商号・勧誘者の氏名・勧誘目的である旨を告げずに勧誘すること                 | AI 会話は `INTRODUCTION → DISCLOSURE → IDENTIFICATION` を経ないと営業状態に入れない（状態機械で強制）                                        |
| 契約を締結しない旨の意思（勧誘を受けたくない旨を含む）を表示した者への勧誘の継続・再勧誘 | 拒否は **STOP_REQUESTED / DO_NOT_CALL の hard suppression**（無期限・全キャンペーン）。AI は拒否検知で強制終話。「興味なし」も対象として扱う |
| 迷惑を覚えさせるような時間の電話                                                         | 組織ポリシーの発信可能時間（既定 09:00–20:00, 日曜・祝日除外）を全発信で強制。時間帯の具体値は法令に明記がないため〔要法務確認〕             |
| 威迫・困惑させる勧誘                                                                     | P12: AI の禁止行為ポリシー（評価セット `evals/` に追加予定）                                                                                 |

## 個人情報保護法

- 利用目的の範囲内で利用（問合せ者への連絡）。ログに電話番号全文・会話全文を出さない（SECURITY.md）。
- 録音（`RECORDING_ENABLED`、既定 OFF）を有効化する場合、冒頭での録音告知と保存期間・アクセス権限を P12 で定義する。〔要法務確認〕
- 第三者の番号（番号誤り）は PRIVACY_BLOCK とし二度と発信しない。

## AI 音声に関する開示

AI が通話する場合、冒頭で AI であることを告知する（DISCLOSURE 状態で扱う）。〔要法務確認: 業界ガイドライン〕

## Kill switch / 緊急停止

`OUTBOUND_KILL_SWITCH` は既定で停止。事故時は即時停止可能（P7 で管理画面からの動的停止を追加）。
