# PRODUCT

## 何を作るか

既存 TAC 自動テレアポアプリ（`https://tac-martial-arts.fly.dev/tac/app`）の後継となる **AI + Human Hybrid Sales Engagement Platform**。
株式会社 Martial Arts の不動産（投資・住宅）営業のテレアポ業務を対象に、「誰に・いつ・どう電話し・結果をどう次に繋ぐか」を
安全（DNC・再勧誘禁止・迷惑時間）を最優先にしてシステム化する。

## 既存業務の理解

> 2026-10-05 更新: 現行 TAC 本体のソース（`hasegawa212/-6780` `telegram-ai-bot/tac/`）を監査した。詳細は **[EXISTING_APP_AUDIT.md](EXISTING_APP_AUDIT.md)**（ADR-0010）。下の表は初期の補助資料。

### 補助資料（ADR-0002 時点）

| 既存資産                                | 読み取れる業務ルール                                                                                                                                                                   |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `テレアポ管理シート.csv`（24列）        | リードは Web 問合せ由来。優先度 A/B/C、面談希望区分、年収/勤続/貯蓄/不動産/投資経験、**電話可能な時間帯**（`9:00~12:00` / `18時以降` 等）、架電日・結果を最大 3 回分、アポ日時、担当者 |
| `apps-script-call-log/`                 | 結果キーワード → ステータス: アポ獲得 / アポ予定 / 次回架電予定（不在・留守・再架電） / 対応不可（拒否・NG） / 番号誤り / 架電済み                                                     |
| `経営管理/03_営業/テレアポ/個別分析.md` | A=面談希望 6 / B=相談したい 17 / C=興味なし 12。属性 × 連絡可能性で架電順を決めている                                                                                                  |

### 新システムでの写像

| 既存                    | 新システム                                                                |
| ----------------------- | ------------------------------------------------------------------------- |
| 架電ステータス/架電結果 | `CallOutcome`（`src/domain/outcome/outcome.ts`）                          |
| 架電日1–3               | Call 履歴（回数は `maxAttemptsPerContact` で上限管理）                    |
| 電話可能な時間帯        | `contactWindowRaw` → `parseContactWindow`（組織ポリシーを**狭めるだけ**） |
| 対応不可（拒否/NG）     | **DNC suppression**（全キャンペーン横断・期限なし）                       |
| 興味なし（C）           | **STOP_REQUESTED suppression**（宅建業法の再勧誘禁止、COMPLIANCE.md）     |

## ペルソナ

- **オペレーター（営業）**: Call Workspace で発信・通話・結果入力。キーボードだけで操作したい。
- **マネージャー**: キャンペーン・キュー・成果の管理、緊急停止（kill switch）。
- **管理者**: テナント設定、権限、予算、コンプライアンス設定。
- **AI Voice Agent**（P12 以降）: 一次対応・ヒアリング。発信の決定権は持たない。

## 非ゴール（当面）

- 完全自動の predictive dialer（`AUTO_DIAL_ENABLED` は既定 OFF、production では P6 まで起動拒否）。
- 既存 GAS / スプレッドシート運用の即時廃止（並走し、P4 で CSV import 互換）。

## 要確認（参照 URL にアクセスできる環境で確認する）

- 既存 TAC アプリの画面導線、キュー割当ルール、録音有無、AI 発話の有無と内容。
- 「アポ予定」と「アポ獲得」の業務上の差。
- 架電上限（現行シートは 3 回分の列）を業務ルールとして採用してよいか。
