## 試算（すべて `build.js` の `calc()` で算出）

サンプル条件：35歳・単身・年収550万円・家賃10万円・預貯金600万円／新築戸建て3,500万円（土地100㎡・建物85㎡・駐車場1台）／頭金300万円・借入3,200万円・年利1.5%（試算用の仮定）・35年・元利均等。

- 毎月返済 **97,979円**、総返済 約4,115万円（利息 約915万円）、返済負担率 21.4%
- 残債：5年 2,839万円 / 10年 2,450万円 / 20年 1,578万円 / 35年 完済
- 本当の住居費（月）：現在の賃貸 約10.6万円 / 戸建て 約12.5万円 / 同等の広さ・駐車場付き賃貸（仮定）約14.7万円
- 10年後売却の手取り（仮定3シナリオ）：下落 −381万円 / 横ばい −49万円 / 上昇 ＋296万円
- 購入後の手元資金は約55万円 → 生活費6か月分（仮定120万円）に不足、と正直に提示し、頭金100万円案（手元255万円・返済104,103円）を併記

**仮定値**（購入諸費用7%・固定資産税等 年12万円・保険・修繕積立 月1.5万円・土地/建物内訳・3シナリオ 等）は `A` オブジェクトにまとめ、スライド上でも「仮定」と明示しています。検算（元金合計＝借入額、35年で残債0）はビルド時にコンソールへ出力されます。

## 住宅ローン控除（`taxcredit.js`・基準日 2026年10月）

デッキ（P19〜21）とシミュレーターは同じエンジン `taxcredit.js`（依存なし・Node/ブラウザ両対応）で計算します。

- **適用判定 `judge()`**：入居年（2026〜2030）、新築／中古／買取再販、住宅性能（認定・ZEH水準・省エネ基準・その他）、性能証明の有無（なければ「その他」扱い）、建築確認日・登記上の建築日（2028年以降の新築省エネ基準＝2027年末までの確認等で2,000万円・10年／新築その他＝2023年末までの確認等で2,000万円・10年）、床面積40㎡（40〜50㎡は合計所得1,000万円以下の年のみ、上乗せは50㎡以上）、合計所得2,000万円、返済10年以上、中古の耐震（1981年以前は証明要）、親族等からの取得、2028年以降のレッドゾーン新築、子育て・若者夫婦世帯の上乗せ。必要書類の一覧も返します。
- **年次計算 `simulate()`**：各年の上限＝min（年末残高, 借入限度額, 取得対価）×0.7%。所得税（控除前）→ 翌年度住民税（課税総所得金額等×5%・最高97,500円・所得割額まで）の順に充当し、**控除しきれない額は加算しません**。制度上の上限と実際の見込額、所得税分・住民税分、控除しきれない額を分けて返します。
- **税額**：詳細モードは源泉徴収票の税額を入力。概算モードは給与所得のみ・単身として推計（社会保険料＝年収×15%、令和8・9年分の基礎控除等の特例が2028年以降も続くと仮定＝税額を低めに見積もる保守的な前提）。概算の結果は「概算」と明示し、確定値として扱いません。
- `node test.js`：46件の検算（返済額・残高0・区分ごとの限度額/期間・経過措置・対象外判定・充当の整合性）。
- 出典：財務省「令和8年度税制改正の大綱」、国土交通省「住宅ローン減税」、国税庁 タックスアンサーNo.1211-1・1211-2。**買取再販住宅の限度額（新築に準じて計算）と住民税控除上限の継続は〔要確認〕**。税制改正で変わるため、配布前に最新の一次資料を確認してください。

## ビルド

```bash
cd single-house-proposal
npm install
node test.js             # 住宅ローン控除エンジンの検算
node build.js            # → dist/単身者向け戸建て提案資料.pptx と 営業トーク台本.md
# シミュレーター：simulator.html をブラウザで開く（taxcredit.js を同じフォルダに置く）
npm run pdf              # → dist/…pdf（LibreOffice が必要）
```

- 条件を変える：`build.js` 冒頭の `A`（試算条件）を書き換えて再ビルド。数値はスライド・ノート・台本すべてに反映されます。
- 会社名：`COMPANY` 定数。写真は `../construction-portfolio/img/`（当社施工事例）を「イメージ」と明記して使用しており、試算の架空物件の写真としては扱っていません。
- フォントは游明朝（見出し）／游ゴシック（本文）を指定。

## 表現上のルール

「NISAより不動産が必ず有利」「家賃は無駄」「土地は必ず資産として残る」「戸建ては必ず売れる」「返済はすべて資産になる」といった断定は使いません。マンションにも敷地の共有持分（敷地利用権）がある点、NISAは投資商品ではなく非課税制度である点を明記しています。住宅ローン控除・税制・金利は年度や商品で変わるため試算に含めず、最新情報の確認を促す注記を入れています。
