# 来期 営業部 組織設計案｜株式会社 Martial Arts

- **作成基準**：2026/7/27 の酒井かいと氏 1on1、および同面談内で語られた各メンバー評価。
- **前提となる経営課題（上長の問題意識）**
  - 6期目・**15億規模**へ成長する一方、**人の出入りが激しく組織分解のリスク**。
  - **誰も自ら立候補しない／給料を上限まで上げられるのに取りにこない**＝責任を負いたくないように見える。
  - **「どの立場でもいい」という当事者意識の薄さ**が最大の困りごと。
  - **“稼ぐ集団” から “人を育てられる企業” への転換**が必要。「なりたい人をならせる」だけでなく **育成できる体制** が要る。

> この組織図の狙いは「頂点を1人決める」ことではなく、**“2番手・3番手を設計して、育成が回る構造” を作る**こと。上長の言葉＝**「まず2番を埋めないと」**。

**設計思想**：酒井氏を筆頭に置きつつ**単独の頂点にはしない**。上田氏（堅実・仕組み）を管理No.2に、俊彦氏を2番手候補として試用、赤西氏を人材ケアのメンター、犬塚氏を新人育成に配置し、**酒井氏に “育てる経験” を積ませる器** を用意する。

## 2. メンバー別 立ち位置・役職・次の役割

### ● 酒井 かいと 氏 — 営業リーダー（筆頭・代表格候補）
> 詳細は [`分析_酒井かいと_20260727.md`](./分析_酒井かいと_20260727.md) 参照。
- **立ち位置**：実質No.1プレイヤー。担がれ型リーダー。
- **推奨役職**：営業部 次長／営業リーダー（代表格候補）。
- **次の役割**：2番手・3番手を任命して育てる／会議で自発的に緊張感を出す（嫌われる勇気）／「ここのトップは自分だ」と当事者宣言。

### ● 上田 氏 — 管理・仕組み No.2（堅実運用リーダー）
- **強み**：今季1位で役職就任済み。**下に優しく気遣い型**。**部下の意見を背負って代弁するのが得意**。**ちゃんと形を作る（堅実・仕組み化）**。面接でも「形を作る」ことができる。
- **課題**：**強く言う・緊張感を与える・自発的に感情を出して引っ張るのが弱い**（怒らず注意止まり）。会議で自発的・感情的には言わない。→ **単独トップ／緊張感役には不向き**。
- **立ち位置**：**堅実に “型” を作り、調整・代弁・仕組み化を担うNo.2**。緊張感役は担わせない設計が正解。
- **推奨役職**：現役職を維持し、**管理・育成の型化・オペレーション**担当のNo.2〜3。
- **次の役割**：面接フローや育成の「形づくり」、部下の声の吸い上げ・代弁。**酒井氏の横で “堅さ” を補完**（酒井の勢い × 上田の堅実さ）。

### ● 俊彦（シュン）氏 — 2番手候補（試用）
- **強み**：**厚い人・扱いやすい・要領もいい**。2番手候補として名が挙がっている。
- **課題**：**「厚い・扱いやすい」以上の決め手が弱い**。独断で前に出すには **経験・押し出しの一言が今は響かない**。給料に対して結果が物足りないという上長評も。
- **立ち位置**：**ポテンシャル枠の2番手候補**。即2番手ではなく **“証明期間” を置く**。
- **推奨役職**：**酒井氏の管理補佐（サブ）として試用**。正式な2番手は結果を見て判断。
- **次の役割**：酒井氏の下で管理の一部を任され、**実績と “押し出し（言い切る力）” を証明**する。要領の良さを実績に変換する期間。

### ● 赤西 氏 — 同格チーム／メンター
- **強み**：**トップ級の売り手**。**優しく、人をめちゃくちゃよく見る**。酒井氏を常に気にかけている。
- **課題**：人を見る力はあるが **“代表向き” は酒井氏**（上長の明確な比較）。緊張感を出して引っ張る役は弱い。
- **立ち位置**：**もう一つのチームを持てるトップ級プレイヤー兼メンター**。代表格ではないが人材ケアの要。
- **推奨役職**：**別ライン（チーム）のリーダー、または人材ケア担当のメンター**。
- **次の役割**：**“人を見る力” を活かしたメンバーのケア・離脱防止**（＝組織分解リスクへの直接の打ち手）。酒井氏と並走し、緊張感役は担わせない。

### ● 犬塚 氏 — 新人育成担当（トレーナー）
- **強み**：**新人育成に向く**。頑張っている。
- **課題**：**まとめ役・2番手には不向き**（“子供” と見られる懸念、後から入る人からの見え方）。責任を取りにくる姿勢が弱い。
- **立ち位置**：**新人オンボーディングの現場担当**。統率ラインには乗せない。
- **推奨役職**：**新人育成担当／トレーナー**（役職＝統率の付与は時期尚早）。
- **次の役割**：新人研修プログラムの運用。**“子供” イメージからの脱却**（結果と責任姿勢の証明）が昇格の条件。

## 3. 立ち位置の見極めフレーム（6軸ルーブリック）

今後の1on1でも **同じ物差し** で判断できるように、上長が面談で重視した観点を6軸に整理した。各軸 0〜5 で採点し、下の対応表で推奨役割を導く。

| 軸 | 見るポイント（1on1での質問例） |
|---|---|
| ① 実績 | 本数・売上・伸び代。「本来もっと売れたか？」 |
| ② 統率（人を扱う） | カリスマ・まとめる力。「メンバーは自然についてくるか？」 |
| ③ 育成（人を教える） | 教えた経験・2番手を育てた実績。「誰かを育てて数字を出させたか？」 |
| ④ 当事者意識 | 責任を取りにいくか。「“どの立場でもいい” になっていないか？」 |
| ⑤ 胆力（嫌われる勇気） | 大義名分なしに自発的に緊張感・感情を出せるか。「会議で自分から言えるか？」 |
| ⑥ 定着・信頼 | 周囲の信頼、辞めさせない力。「この人がいると人が残るか？」 |

### 採点 → 推奨役割の対応表（上から優先判定）

| 優先 | 条件（目安） | 推奨する立ち位置・役職 |
|:--:|---|---|
| 1 | ①≥4 かつ ②≥4 かつ ④≥3 かつ ⑤≥3 | **代表格／営業責任者**（頂点を任せられる） |
| 2 | ①≥4 かつ ②≥4 | **プレイングリーダー／代表格候補**（2番手を付けて育成前提）※酒井氏はここ |
| 3 | ①≥4 かつ ⑥≥5 | **同格チームリーダー／メンター**（人材ケア・離脱防止）※赤西氏はここ |
| 4 | ③≥3 かつ ②≥3 かつ ⑤<3 かつ ⑥≥3 | **管理・仕組みNo.2**（代弁・調整・型づくり）※上田氏はここ |
| 5 | ③≥3 かつ ②<3 | **新人育成トレーナー**（統率ラインに乗せない）※犬塚氏はここ |
| 6 | ②≥3 かつ ⑥≥3 だが ①<4 または ⑤<3 | **2番手候補（試用）**（証明期間を置く）※俊彦氏はここ |
| 7 | 上記いずれにも満たない | **プレイヤー（底上げ）**（実績づくりに専念） |

※上から順に最初に該当した行を採用（付属 `index.html` に同ロジックを実装）。閾値は面談での重み付けを反映したたたき台であり、運用しながら調整可能。

> このルーブリックは付属の HTML ボード（`index.html`）に実装済み。6軸を入力すると推奨役割が自動で出ます。1on1のたびに1人ずつ追加していけば、来期組織図の下敷きが積み上がります。

## 4. 組織づくりの重点（まとめ）

1. **頂点を決める前に “2番手・3番手の構造” を作る**（上長：「まず2番が大事」）。
2. **緊張感役（嫌われる勇気）は希少資源**。現状は部長と酒井氏のみ。→ **酒井氏に意図的に担わせ、鍛える**。
3. **人材の離脱防止＝赤西氏のケア力を組織的に使う**。組織分解リスクへの直接策。
4. **育成の “型化” は上田氏、育成の “現場” は犬塚氏**に分担し、**“人を育てられる企業” への転換**を仕組みで実現。
5. **「どの立場でもいい」を放置しない**。役職付与とセットで **当事者宣言** を求める運用にする。
