# sales-org-1on1 — 営業部 1on1・立ち位置分析

株式会社 Martial Arts 営業部の **来期組織図づくり** に向けて、1on1面談の結果から
各メンバーの **立ち位置・役職・次の役割** を分析・可視化するための一式です。

「1on1の結果を入れていくので、その人にあった立ち位置を分析して役職・次の役割を明確にしたい」
という依頼に応え、**今回の分析** ＋ **今後も同じ物差しで判断できる再利用ツール** をセットにしています。

## 使い方

```
cd sales-org-1on1
python3 -m http.server 5183     # → http://localhost:5183
```
（`index.html` をブラウザで直接開いてもOK。完全にクライアント側で動作します。）

1. 起動すると、面談メモの **5名がプリセット** された状態で組織図・カードが表示されます。
2. `＋ 1on1結果を追加` から、新しく1on1した人を **6軸（0〜5）** で採点 → 推奨される立ち位置がその場で出ます。
3. 保存すると組織図・メンバー一覧に反映。`印刷 / PDF` で経営会議用の資料として出力できます。
4. データは端末の localStorage のみに保存（サーバー送信なし）。`書き出し(JSON)` / `読み込み` で端末間の受け渡しやバックアップが可能。

## 6軸ルーブリック（判断の物差し）

| 軸 | 見るポイント |
|---|---|
| ① 実績 | 本数・売上・伸び代 |
| ② 統率 | 人を扱う・カリスマ・まとめる力 |
| ③ 育成 | 人を教える・2番手を育てた経験 |
| ④ 当事者 | 責任を取りにいくか（“どの立場でもいい”を脱せるか） |
| ⑤ 胆力 | 嫌われる勇気・自発的に緊張感を出せるか |
| ⑥ 定着 | 信頼・辞めさせない力 |

採点 → 推奨役割の対応ロジックは `組織設計_来期営業部.md` に記載、`index.html` の `recommend()` に実装済み（両者は一致）。閾値は面談での重み付けを反映した **たたき台** で、運用しながら調整できます。

## データソースについて

- 一次情報は **2026/7/27 の酒井かいと氏 1on1 面談メモ（文字起こし）** です。
- Slack連携先も確認しましたが、社内には「お客様お電話報告」通知しか無く、営業部メンバーの内部評価データは見当たりませんでした。よって分析は面談メモを唯一の一次情報として構成しています。
- 数字（本数・売上）・固有名詞（人名）は自動文字起こしに基づく **参考値** です。重要事項は原音源・正式資料でご確認ください。
- 本資料は **人事評価に関わる機微情報** を含みます。取り扱い・共有範囲にご注意ください。
