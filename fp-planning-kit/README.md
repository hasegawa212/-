# fp-planning-kit — FPと始めるライフプランニング資料

顧客に送れる、**A4・印刷/PDF対応の「ファイナンシャル・プランニング（FP）相談導入」資料**（ゼロ依存の単一HTML）。日本FP協会の実務データ・ガイダンスを土台に、「なぜ今ライフプランニングか → お金の6分野 → FPの手法（キャッシュフロー表／バランスシート）→ 相談の進め方」を1本にまとめ、**無料相談CTA**で締めます。FP／金融リテラシー営業（既定は株式会社ジャパンマネジメント）の入口資料としてそのまま配布できます。

`pension-planning-kit`（年金中心）／`lifeplan-home-kit`（マイホーム中心）に続く**総合ライフプランニングの入口**にあたる姉妹資料です。ティール×ゴールドの配色で前2作（ネイビー／チャコール）と差別化しています。

## 使い方

- ローカルで開く：`cd fp-planning-kit && python3 -m http.server 5185` → http://localhost:5185
  （`index.html` を直接開いてもOK。完全にクライアントサイド動作）
- **PDF/印刷**：右上「🖨 PDF / 印刷で保存」→ ブラウザ印刷で「PDFに保存」。A4・10ページ（表紙＋本編9）で出力（A4 = 794×1123px @96dpi）。
- **文字の編集**：「✎ 編集ON」で会社名・電話・URL・コピー等をクリック編集。`localStorage`（`fp_planning_kit_v1`）に自動保存。「↺ 初期化」で復元。既定は閲覧モード。

## 構成（A4 全10ページ／表紙＋本編9）

1. **表紙** — 「お金の不安を、地図に変える。」
2. **なぜ今、ライフプランニングか** — インフレ／人口減少／貯蓄から投資／自己責任時代
3. **データで見る「お金の現実」** — 平均給与の推移（男女計459.5万円・男女差）／金融リテラシー正答率 約55%／財形貯蓄実施企業 36.9%
4. **お金の6分野** — ライフプランニング／金融資産運用／リスク管理／タックス／不動産／相続・事業承継
5. **FPの武器①キャッシュフロー表** — 将来の収支・貯蓄残高を年表化（教育ピーク・老後の取り崩し）
6. **FPの武器②バランスシート** — 資産・負債の棚卸し＝純資産（家計の健康診断）
7. **ライフイベントとお金** — 誕生〜相続の6ステージ＋3大資金＋ライフデザイン
8. **相談の進め方** — 現状把握→目標設定→プラン作成→実行・見直し（PDCA）
9. **「FP」って誰？** — 資格体系（3級/2級・AFP/1級・CFP®）と中立の価値
10. **無料相談CTA** — 相談前に用意するもの、会社情報（編集可）

## 編集のポイント

- **会社情報は `data-k` 付き要素**（表紙・各フッター・CTAの連絡先など）。ブラウザ編集で書き換えられ `localStorage` に保存。既定値を恒久的に変えるなら `index.html` の該当テキストを直接編集。既定ブランドは **株式会社ジャパンマネジメント**。
- **数値の扱い**：データ集の数値は出典・調査年次を明記（調査年で更新されます）。制度・目安が変わる項目は `〔要確認〕`。各ページ下部＋最終ページに免責を記載。
- **印刷レイアウト**：印刷ルールは `.page{height:296mm}`（固定高、`min-height` ではない）で、背景・フッターがA4下端まで伸びつつ末尾の空白ページが出ないようにしています（`pension-planning-kit`／`lifeplan-home-kit` と同じ対策）。モバイル用ブレークポイントは `@media screen and (max-width:760px)`（印刷=794pxには効かない）。
- **キャッシュフロー表／バランスシートの数値はイメージ**（万円）。実際は面談で個別に作成します。

## 出典

いずれも日本FP協会の資料に基づきます。

- **FP実務の基本データ集**：平均給与の推移（国税庁「民間給与実態統計調査 令和5年分」）／金融リテラシー調査（金融広報中央委員会 2022年）／貯蓄制度の種類別実施企業割合（厚生労働省「就労条件総合調査 令和6年」）
- **FP初級向けガイダンス**：FPの役割・6分野・ライフプラン手法（キャッシュフロー分析／バランスシート分析）・資格制度

本資料は情報提供のみを目的とし、特定の金融商品等の勧誘や個別の投資・税務・法務助言ではありません。CFP®は日本FP協会の登録商標です。配布前に各出典の最新版を確認してください。

## メンテナンス

ビルド／テスト／Lint なし。デザインは `index.html` 内の `<style>`、文面は該当HTMLを直接編集します。
