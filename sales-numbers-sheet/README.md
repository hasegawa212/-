# sales-numbers-sheet — 営業部 数字シート

株式会社 Martial Arts 営業部の全員に配る「会社の数字」1枚シート。
「アポの数字は分かるけど、金額の数字は分からない」という状態を変えるために、
会社の金額目標をアポや決済の本数に置き換えて見せます。

## 中身（上から順に）

1. **結論**：赤字にならないのは月◯決済、今は◯本（固定費 ÷ 1決済の利益）
2. **お金の足し算と引き算**：出ていくお金 / 入ってくるお金 / 差し引き、これまでの目標と着地
3. **キャンペーンのファネル**：アポ→入室→再訪→内見→購入意思→契約→決済と通過率。詰まり①（入室→再訪）と②（契約→決済）
4. **逆算**：アポ1本あたりの利益、目標達成に必要なアポ数と今の何倍か
5. **11月の見通し**：目標本数と名前が挙がっている本数
6. **自己チェック**：何も見ずに答えられるべき4問（答えは開くと表示）
7. **今週から全員でやること**

## 使い方

```
cd sales-numbers-sheet
python3 -m http.server 5189     # → http://localhost:5189
```
`index.html` を直接開いてもOK。ゼロ依存・単一HTML・ビルドなし。

- 上部の「毎月の固定費 / 1決済の利益 / 今月の決済」を変えると全体が再計算されます。
- ページ下の「数字を更新」でファネル・11月・過去実績を毎週差し替え。入力はその端末の localStorage（`ma_sales_numbers_sheet_v1`）にだけ保存。「会議時点の数字に戻す」で初期値へ。
- 印刷（Ctrl/⌘+P）で A4。入力欄・更新パネルは印刷に出ません。

## 数字の扱い

- 初期値は 2026年10月の営業会議での発言（音声書き起こし）からの**概算**です。固定費 2,700万円・1決済の利益 600万円・ファネル 123→62→36→16→13→9→2・11月 24本中9本 など。経理の確定値で差し替えてから配ってください。
- **社外秘**。会社の損益に関わる数字を含むため、GitHub Pages / Netlify への公開対象には入れていません。
