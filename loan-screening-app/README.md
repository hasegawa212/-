# LOAN DESK — 住宅ローン審査アプリ（iPhone向け）

銀行の住宅ローン審査の流れを再現した審査アプリです。申込内容を入れて「審査を実行」すると、

1. **足切り基準**（申込年齢・信用情報の異動・団信・再建築不可・最低年収・完済年齢）
2. **返済能力**（審査金利で計算した返済比率、年収倍率、所得の安定性）
3. **担保評価**（物件の種類・築年数・旧耐震から担保評価額と掛目）
4. **スコアリング**（8項目・1000点 → 格付 A〜E）

の順に判定し、**承認見込み／条件付き承認見込み／要再検討／否決見込み**、**融資可能額**（返済比率・年収倍率・担保評価のいちばん厳しい制約で決まる額）、**稟議所見**（評価できる点・懸念点・条件・次にやること）、**条件を変えると**（他の借入を完済・期間延長・減額・収入合算）を出します。

> 実際の審査基準は金融機関ごとに異なり公開されていません。この結果は一般的な考え方に基づく **目安** で、承認・融資を約束するものではありません。信用情報は自己申告で、照会はしていません。特定の金融機関の名前・ロゴは使っていません。

## 使い方

- `index.html` を直接開く、または `npm run serve` → http://localhost:5190
- 1ファイルで送るとき: `npm run build` → `dist/LOAN_DESK.html`
- テスト: `npm test`（node --test）

## 画面（下のタブ）

| タブ | 内容 |
|---|---|
| 申込入力 | 6区分（申込人／収入／借入の希望／物件・担保／他の借入／信用情報・団信）。上のバーに借入額・返済比率・年収倍率がリアルタイムで出ます。最初はサンプル案件が入っています |
| 審査結果 | 判定の印影・格付・スコア、融資可能額、毎月の返済、審査項目（○△×）、スコア内訳、条件を変えると、稟議所見（決裁欄つき）。所見はコピーできます |
| 案件一覧 | 「案件に保存」した審査（この端末の localStorage `lsa_cases_v1` のみ。お名前はイニシャルだけ） |
| 審査基準 | 審査金利・年収帯ごとの返済比率上限・年収倍率・年齢・勤続・担保掛目などを変更（`lsa_policy_v1`） |

## 標準の審査基準（`lib/screening.js` の `POLICY`）

| 項目 | 標準 |
|---|---|
| 審査金利 | 3.5% |
| 返済比率の上限 | 年収300万円未満 25% / 400万円未満 30% / 400万円以上 35% |
| 年収倍率 | 7倍以下（9倍超は減額でも難しい） |
| 申込年齢 / 完済年齢 | 20〜70歳 / 80歳以下、最長35年 |
| 勤続 | 会社員1年以上、自営業・経営者は3期 |
| 担保掛目 | 100%以下（諸費用込み110%） |
| 収入合算 | 合算者の年収の50%を算入 |

自営業・経営者は直近2期の低いほうの所得で審査します。

## ファイル

- `lib/screening.js` — 審査エンジン（UMD、ブラウザでは `window.LSA`）。基準・配点・判定ルールはここだけ
- `index.html` — iPhone向けの画面（外部への送信なし）
- `test/screening.test.js` — エンジンのテスト
- `tools/bundle.js` — 1ファイル版を作る
