# LOAN DESK — 住宅ローン審査システム（iPhone向け）v3

銀行・保証会社の住宅ローン審査ラインを、同じ段取りと項目で再現した審査アプリです。設計と計画は [`docs/設計.md`](docs/設計.md)。

## できること

- **審査の型**: 都市銀行型／ネット銀行型／地方銀行型／**信用金庫型**／**フラット35型**。数字は「審査基準」タブで相手の金融機関に合わせて変えられる
- **フラット35**: 融資率（借入÷物件価格）9割超の金利上乗せ、新機構団信（入らなければ −0.2%）、子育てプラス・フラット35S（ZEH／金利A・Bプラン）のポイントによる当初金利の引下げ、借入額100万〜8,000万円、返済期間15〜35年、申込70歳未満・完済80歳未満、旧耐震は ×、適合証明書
- **信用金庫**: 営業地域内の居住・勤務（地域外は対象外）、一定額（700万円）を超える借入は会員（出資金）、系統の保証機関による保証審査
- **保証機関と費用**: 保証機関（銀行系の保証会社／信用金庫の系統保証機関／保証料なし／フラット35は保証会社なし）、保証料（金利上乗せ型／一括前払い型）、事務手数料（定額／定率）、借入時の費用の合計。信用保証協会（事業資金の保証）は住宅ローンを扱わない旨も表示
- **審査の段階**: 事前審査（自己申告で判定）と本審査（書類の確認も判定。未確認なら「書類の確認待ち」）
- **審査ライン（9工程）**: 本人確認・反社 → 信用情報（CIC・JICC・KSC） → 申込人 → 収入 → 返済能力 → 担保・物件 → 保証会社の判定 → 書類 → 決裁。工程ごとに ○△× と根拠を表示
- **担保評価**: 中古戸建は積算評価（土地＝路線価×面積、建物＝再調達単価×延床×残りの耐用年数）。接道・建ぺい率と容積率の超過・市街化調整区域・借地権・床面積・用途も判定
- **結果**: 承認／条件付き承認／保留／否決（すべて「見込み」）、融資可能額（どの制約で上限が決まったか）、保証会社の格付・保証料・適用金利の目安、決裁権限（金額と例外の有無）、必要書類、稟議所見（コピー可）、条件を変えた場合の比較、審査記録（日時・型と版・エンジンの版・入力のハッシュ）

> フラット35と信用金庫の条件は、2026年10月時点の公開情報と金融機関の資料に基づく目安です（調べた内容は `docs/設計.md` の7章）。実在の金融機関の名前・内部基準は使っていません。型の数字は公開情報から見た一般的な水準の目安です。結果は承認・融資を約束するものではなく、最終判断は金融機関が行います。信用情報は自己申告で、照会はしていません。

## 使い方

- `index.html` を直接開く、または `npm run serve` → http://localhost:5190
- 1ファイルで送るとき: `npm run build` → `dist/LOAN_DESK.html`
- テスト: `npm test`（node --test、55件）

## ファイル

| ファイル | 中身 |
|---|---|
| `lib/policy.js` | 4つの型の審査基準（`PRESETS`）と `resolvePolicy`。基準の数字はここだけ |
| `lib/income.js` | 審査年収（会社員は直近、自営業・経営者は型の基準。収入合算は連帯保証と連帯債務で割合が違う） |
| `lib/credit.js` | 3機関の信用情報。異動・官報は足切り。申込件数は機関ごとの最大値 |
| `lib/collateral.js` | 担保評価（積算・簡易・価格・手入力）と物件の適格性 |
| `lib/flat35.js` | フラット35の金利（融資率9割超・団信・ポイント制の引下げ） |
| `lib/fees.js` | 保証料（金利上乗せ型／一括前払い型）と事務手数料 |
| `lib/screening.js` | 審査ライン・判定・融資可能額・保証会社・決裁・書類・審査記録・所見 |
| `index.html` | iPhone向けの画面。下のタブで 申込入力／審査結果／案件一覧／審査基準 を切り替える |
| `test/*.test.js` | モジュールごとのテスト |

保存先はこの端末の localStorage だけです: 案件 `lsa_cases_v2`（お名前はイニシャルのみ）、基準 `lsa_policy_v2`。外部には送信しません。
