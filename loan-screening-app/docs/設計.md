# LOAN DESK v2 設計書 — 銀行の住宅ローン審査システムと同じ水準へ

## 1. 目的

v1 は「返済比率・年収倍率・簡易な担保評価・スコア」だけの目安でした。v2 では、金融機関と保証会社が実際に見ている審査の段取りと項目を同じ水準で再現します。

- **審査の段階**: 事前審査（自己申告）と本審査（書類確認）を分ける
- **審査ライン（工程）**: 本人確認・反社 → 信用情報（3機関） → 申込人 → 収入 → 返済能力 → 担保・物件 → 保証会社判定 → 書類 → 決裁。各工程が ○△× と所見を持つ
- **審査基準の型**: 都市銀行型／ネット銀行型／地方銀行型／フラット35型のプリセット。数字は画面で変えられる
- **記録**: 審査記録（日時・基準の型と版・エンジンの版・入力のハッシュ・判定）を残し、同じ入力からは同じ結果が出ることを保証する

実在の金融機関の名前・ロゴ・内部基準は使いません。各行の基準は公開されていないため、型の数字は一般的な水準の目安です。結果は承認を約束せず、最終判断は金融機関です（`NOTE`、テストで常に表示を確認）。

## 2. 実務との対応

| 工程 | 実務で見ていること | v2 での扱い |
|---|---|---|
| ① 本人確認・反社 | 本人確認（犯収法）、反社会的勢力の照会 | 反社に該当すれば足切り。本人確認が済んでいなければ、本審査では保留 |
| ② 信用情報 | CIC・JICC・KSC（全銀協）の3機関。異動（61日以上の延滞・代位弁済・債務整理）、官報情報（破産）、申込情報（CIC・JICC 6か月／KSC 1年） | 機関ごとに入力する。異動・官報は足切り。直近の延滞は△。申込件数は機関ごとの最大値で判定（同じ申込が複数機関に載るため、合計はしない） |
| ③ 申込人 | 年齢・完済年齢、国籍（永住権）、雇用形態、勤続、団信 | 永住権がない場合の扱い（否決／△）は型ごとに設定。団信に入れなければ足切り（フラット35型は団信が任意なので△） |
| ④ 収入 | 会社員は源泉徴収票（前年）。自営業は確定申告3期（平均または低いほう）。経営者は役員報酬に加えて法人決算3期（赤字） | `incomeBasis`: avg3（3期平均）／min2（直近2期の低いほう）／latest（直近）。法人の赤字が2期以上なら×、1期なら△ |
| ⑤ 返済能力 | 審査金利（フラット35は実際の金利）での返済負担率、年収倍率、完済年齢、他の借入（カードは利用枠で見積もる行もある） | `stressRate: null` なら実際の金利で計算。カードローン枠の算入率は型ごとに設定 |
| ⑥ 担保・物件 | 積算評価（土地＝路線価×面積、建物＝再調達価格×延床×残存年数÷耐用年数）、担保掛目、接道義務（2m）、建ぺい率・容積率の超過、市街化調整区域、借地権、床面積、用途（自己居住） | 戸建は積算評価。マンション、または土地・建物の数字がないときは評価率による簡易評価。接道2m未満・再建築不可・投資用は足切り |
| ⑦ 保証会社 | 格付けに応じた保証料（金利上乗せ型）と金利の優遇幅 | 格付 A〜D → 保証料率・金利の上乗せ・適用金利の目安 |
| ⑧ 書類 | 本審査では原本・写しの確認が済んでいること | 職業ごと・型ごとの必要書類リスト。本審査で確認が済んでいなければ「保留（書類確認待ち）」 |
| ⑨ 決裁 | 金額と例外の有無で決まる決裁権限（支店長／本部審査部／役員） | 借入額の帯で決め、例外（△を承認する場合）があれば1段上げる |

## 3. エンジンの構成（`lib/`、すべて依存なしの UMD・純関数）

| ファイル | 公開するもの |
|---|---|
| `policy.js` | `PRESETS`（4つの型）、`resolvePolicy(id, overrides)`、`POLICY_VERSION` |
| `income.js` | `incomeUsed(x, P)` → `{ own, joint, total, basis, notes }` |
| `credit.js` | `creditSummary(x)` → `{ knockout, worstLate, applyMax, kanpo, items }` |
| `collateral.js` | `appraise(x, P)` → `{ method, land, building, value, rate }`、`eligibility(x, P)` → 物件の判定結果 |
| `screening.js` | `screen(x, policyIdOrObj, { now })` → 工程・判定・融資可能額・保証会社・決裁・書類・審査記録・所見・条件を変えた場合 |

`screening.js` は他の4つを読み込みます（Node では `require`、ブラウザでは `LSA` に集める）。基準の数字は `policy.js` にだけ置きます。

### 判定の順番

1. 足切りに当たる（反社・異動・官報・団信不可（型による）・投資用・接道2m未満・再建築不可・年齢・最低年収・完済年齢） → **否決**
2. 格付が E → **否決**
3. 金額以外の × がある → **保留**
4. 金額の × がある（返済比率・倍率・掛目）、または希望額が融資可能額を超える → 可能額が希望額の50%以上なら **条件付き承認**（減額）、未満なら **否決**
5. 本審査で書類の確認が済んでいない → **保留（書類確認待ち）**
6. 格付が D → **保留**、格付が C か △ が3つ以上 → **条件付き承認**、それ以外 → **承認**

## 5. テスト観点（抜粋）

- 4つの型が同じ項目を持ち、フラット35型は実際の金利で計算し、勤続年数を問わない
- 異動・官報がどの機関に1つでもあれば否決。申込件数は合計ではなく最大値
- 積算評価: 土地＋建物の計算、木造は築22年で建物の評価が0、マンションは簡易評価
- 接道2m未満・投資用は足切り。市街化調整区域・借地は型によって × か △
- 自営業の avg3／min2／latest、経営者の法人赤字、収入合算（連帯保証50%／連帯債務100%）
- 格付から保証料・金利の上乗せが決まり、決裁権限は金額で上がり、例外があれば1段上がる
- 本審査で書類の確認が済んでいなければ保留。すべて済めば保留にならない
- 審査記録は同じ入力と同じ日時なら同じハッシュになり、入力が1つ変わればハッシュも変わる
- 断定・約束の言葉を使わない。`NOTE` を常に返す

# v3 追加設計 — フラット35の詳細・信用金庫型・保証会社（保証機関）

## 6. 目的

- **フラット35**: 公庫系の固定金利ローンとして、銀行型とは別の物差しで判定する（融資率・金利引下げ・団信の扱い・借入額の範囲・耐震）
- **信用金庫型**: 営業地域と会員（出資金）という信金ならではの条件と、系統の保証機関による保証審査を入れる
- **保証会社・保証機関**: 「誰が保証するか」「保証料をどう払うか（金利上乗せ／一括前払い）」「事務手数料」まで出し、借入時の費用を見えるようにする

※ **信用保証協会**は中小企業・個人事業主の**事業資金**を保証する公的機関で、住宅ローンの保証は扱いません。住宅ローンの保証は、民間の保証会社（銀行系・信金系・独立系）が担います。画面にもこの区別を表示します。

## 7. 調べた事実（2026年10月時点の公開情報・一部の金融機関資料。最新は各機関で確認）

| 項目 | 内容 | 扱い |
|---|---|---|
| フラット35 年齢 | 申込時 満70歳未満、完済時 80歳未満 | `ageMax 69`、`payoffAgeMax 79` |
| フラット35 返済負担率 | 年収400万円未満 30%、400万円以上 35%（実際の金利で計算） | 既存 |
| フラット35 団信 | 任意。新機構団信は金利に含まれる。加入しない場合は金利が下がる | 不加入なら −0.2%（目安） |
| フラット35 融資率 | 9割超は金利が上がる（例: 2026年9月 21〜35年 9割以下 3.46%／9割超 3.57%、差 0.11%） | `highLtvAdd 0.11`（目安） |
| フラット35 金利引下げ | ポイント制。子育てプラス（18歳未満の子1人につき1pt、子がいなくても夫婦のどちらかが40歳未満なら1pt）、S（ZEH 3pt／金利Aプラン 2pt／金利Bプラン 1pt）。1ptにつき当初5年間0.25%、最大1.0%。5pt以上は6〜10年目に (pt−4)×0.25% | `flatReduction(x)` |
| フラット35 借入額 | 100万円以上 8,000万円以下、購入価額（建設費）の100%以内 | `loanMin/loanMax`、融資率は**物件価格**基準（`ltvBase: "price"`） |
| フラット35 物件 | 技術基準の適合証明が必要。戸建は床面積70㎡以上、マンションは30㎡以上。旧耐震は耐震評価が必要 | 旧耐震は × |
| フラット35 費用 | 保証料・保証人は不要。融資事務手数料は金融機関ごと（定率2.2%の例が多い） | `guarantor.type "none"`、`adminFee` |
| 信用金庫 地域 | 営業地域内に居住または勤務していること | 地域外は足切り |
| 信用金庫 会員 | 借入が一定額（例 700万円）を超えると会員（出資金の払込み） | 条件と書類に追加 |
| 信用金庫 条件 | 前年年収100万円以上の例、満18歳以上70歳未満、完済80歳以下 | 型の数字 |
| 信用金庫 保証 | 系統の保証機関が金庫とは別に保証審査をする。保証料の例: 1,000万円・30年・一括払いで170,000円 | 一括保証料の表 |

## 8. エンジンの変更

- `policy.js`: `shinkin`（信用金庫型）を追加。全型に `guarantor`（type・label・一括保証料の表）、`adminFee`（fixed／rate）、`loanMin/loanMax`、`termMin`、`ltvBase`（collateral／price）、`requireNewQuake`、`highLtv`（閾値と上乗せ）、`requireArea`、`memberThreshold` を追加。`GUARANTOR_NOTE`（信用保証協会との違い）
- `flat35.js`（新規）: `flatPoints(x)`、`flatReduction(points)` → 期間ごとの引下げ、`flatRate(x, P, ltv)` → 基準金利＋9割超の上乗せ＋団信の扱い−引下げ
- `fees.js`（新規）: `guaranteeCost(x, P, grade, loan, term)` → 金利上乗せ型／一括前払い型、`adminFee`、合計の初期費用
- `screening.js`: フラット35型は `flatRate` を適用金利に使い、融資率を物件価格で判定し、借入額の範囲・旧耐震・団信を判定する。信用金庫型は営業地域と会員を判定する。保証会社の工程に保証機関・支払い方法・費用を載せる

## 9. テスト観点（追加）

- 5つの型が同じ項目を持ち、信用金庫型は地域条件と会員の閾値を持つ
- フラット35: 融資率9割超で金利が上がる。子2人なら当初5年0.5%下がる。ZEH＋子2人（5pt）なら当初5年1.0%、6〜10年目0.25%。団信に入らなければ0.2%下がる。借入額8,000万円超・100万円未満は×。旧耐震は×。融資率は物件価格で計算する
- 信用金庫型: 営業地域外は否決。会員の閾値を超えると条件と書類に出資金が出る
- 保証料: 一括前払い型は借入額と期間に比例し、格付が下がるほど高い。金利上乗せ型は適用金利に足される。フラット35は保証料0、ネット銀行型は保証料0で事務手数料が定率
- 信用保証協会は住宅ローンを扱わない旨の文言を常に返す
