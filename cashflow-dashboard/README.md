# cashflow-dashboard — 資金繰りダッシュボード

銀行の**取引明細CSVをドロップするだけ**で、残高推移・月次収支・カテゴリ別支出・取引先ランキング・資金繰りアラートを一枚で見るツール。**ゼロ依存の単一HTML**（ビルド不要）。UIは日本語。既定ブランドは株式会社 Martial Arts。

**明細はブラウザの中だけで処理されます。**サーバー送信も外部API呼び出しも一切ありません（`fetch`/`XHR` をコード中で使っていません）。

## 使い方

```bash
cd cashflow-dashboard && python3 -m http.server 5188   # → http://localhost:5188
```

インストール・ビルド不要。`index.html` をブラウザで直接開いても動作します（完全クライアントサイド）。

1. CSVをページにドロップ（または「ファイルを選ぶ」）。**複数ファイルをまとめて投入でき、重複行は自動で除外**されるので、毎月の明細を足していけます。
2. まず触ってみるなら **「サンプルで試す」**（架空データを生成。個人情報は含みません）。
3. `🖨 印刷 / PDF保存` でブラウザの印刷ダイアログ → A4でPDF化。印刷時は自動で**明色パレット**に切り替わります（背景グラフィックをONにしてください）。

## 対応CSV

楽天銀行「取引明細」形式が既定です。

| 列 | 例 |
|---|---|
| `取引日` | `20260601` / `2026/06/01` / `2026-06-01` |
| `入出金(円)` | `-5689`（符号付き1列）|
| `残高(円)` | `20544719`（任意。無い場合は残高推移が出ません）|
| `入出金先内容` | `トウテ゛ンテ゛ンキリヨウキン` |

- **文字コードは Shift_JIS / UTF-8 を自動判別**します（BOM対応）。
- 列名は**ゆるく照合**するので、`日付`・`金額`・`摘要` などの別表記でも読めます。`入金`／`出金`が**2列に分かれた形式**にも対応（符号付き1列があればそちらを優先）。
- ヘッダ行はファイル先頭でなくても構いません（`取引日`らしき列を持つ最初の行を探します）。

## 画面

| ブロック | 内容 |
|---|---|
| **KPI** | 期末残高／実質収支（振替除く）／入金・出金合計／自社間振替（純）／期間中の最低残高 |
| **アラート** | 危険水域割れ・連続赤字月・3か月連続悪化・大口支払いの同日集中・調達/信販の重さ |
| **残高推移** | 日次の最終残高（折れ線＋クロスヘア）。破線が危険水域ライン |
| **月次 入金・出金** | 月ごとのグループ棒 |
| **月次 純収支** | ゼロ基準の発散棒（上＝黒字／下＝赤字） |
| **カテゴリ別 支出** | 横棒。最大カテゴリが突出する場合は2位基準で目盛りを取り、その旨を明記 |
| **取引先ランキング** | 入金元・支払先 各TOP20（同一名義を合算） |
| **取引明細** | 全件テーブル。検索・カテゴリ・入出金・金額下限で絞り込み |

各チャートには **「表で見る」** があり、同じ値を表で読めます（色だけに依存しません）。

## 設計上の要点

### 「実質収支」＝自社口座間の振替を除いた収支

同じ会社の別口座への資金移動は、入出金として計上すると収支を歪めます。設定の **自社口座キーワード**（既定 `マーシャルアーツ`）に当たる取引は `自社間振替` として**収支・ランキング・カテゴリ集計から除外**し、KPIに純額だけを表示します。

判定は**受取人側の文字列だけ**を見ます。振込明細の `（依頼人名：カ）◯◯◯）` には必ず自社名が入るため、摘要全体で照合すると**すべての送金が自社間振替になってしまう**ためです（`headOf()`）。

### 表記ゆれの正規化（`normKana` / `matchKey`）

銀行CSVは半角カナ由来で、`セソ゛ン`（基底＋分離した濁点）、`マ－シヤル`（全角ハイフン＋大書きヤ）のような表記になります。そのままでは「セゾン」「マーシャルアーツ」で当たりません。

- `normKana()` … NFKC正規化 →「基底＋゛/゜」を合成（`セソ゛ン` → `セゾン`）。**NFKCは単独の `゛` を「空白＋結合濁点」に分解する**ため、間の空白も許して合成しています。表示にもこの正規化後の文字列を使います。
- `matchKey()` … 突き合わせ専用キー。ひらがな→カタカナ、長音・ハイフン類の除去、小書き→大書き、括弧・記号・空白の除去。これにより **`マーシャルアーツ` が `カ）マ－シヤル　ア－ツ` に一致**します。ルールも検索欄も、人が書いたとおりに当たります。

### 分類ルール

`⚙︎ 設定・分類ルール` で編集。**1行 = `カテゴリ名 , キーワード1 | キーワード2 …`**、上の行から順に判定し**最初に当たったカテゴリ**を採用します。`__SELF__` は自社口座キーワードを指す特別な値です。

どのルールにも当たらない取引は、摘要が銀行振込の形（`◯◯支店 … 普通預金`）なら `振込（仕入・外注等）` / `入金（振込）`、それ以外は `その他出金` / `その他入金` になります。

## データの保存について

- **明細は既定で保存しません。**ページを再読み込みすると消えます。
- ツールバーの **「このブラウザに保存する」** をONにしたときだけ、localStorage（`ma_cashflow_data_v1`）に保存します。ONにする際は確認ダイアログが出ます。OFFに戻すと即座に削除されます。
- 設定と分類ルールは常に保存されます（`ma_cashflow_dashboard_v1`）。明細は含みません。
- **取引明細には取引先の氏名・口座番号が含まれます。**このリポジトリに明細CSVや、そこから生成した出力をコミットしないでください（`.gitignore` で `cashflow-dashboard/*.csv` を除外しています）。

## 構成

すべて `index.html` に同梱（markup＋CSS＋JS）。外部依存なし・ビルドステップなし（`construction-book` / `echo-interview-console` と同じ系統）。

| 関数 | 役割 |
|---|---|
| `decodeBytes` / `parseCSV` / `readStatement` | 文字コード判別、CSVパース、列の照合と取引行の抽出 |
| `normKana` / `matchKey` / `headOf` / `counterparty` | 表記ゆれの正規化と相手先の抽出 |
| `parseRules` / `classify` / `isTransfer` | 分類ルールの解釈と判定 |
| `aggregate` | 月次・日次残高・カテゴリ・ランキングの集計（純関数的に `AGG` を組み立てる） |
| `chartBalance` / `chartInOut` / `chartNet` / `chartCats` | 手書きSVGのチャート（ライブラリ不使用） |

チャートの色は **CSSカスタムプロパティ**（`--s1` 入金・主系列 / `--s2` 出金）で持ち、`@media print` で明色パレットに差し替えています。ダーク面 `#171b21`・印刷面 `#ffffff` の双方で、色覚特性・コントラストの検証を通した組み合わせを使っています。**色を変えるときは両モードで検証し直してください。**

チャートは実寸で描き直す方式（`ResizeObserver`）です。`viewBox` の引き伸ばしだと文字が歪むためで、幅を変えたら再描画されます。

## カスタマイズ

- **ブランド差し替え** … `<title>` と `<header>` の3行。
- **既定のしきい値・分類ルール** … `DEFAULT_CFG` / `DEFAULT_RULES`。
- **アラートの条件** … `renderAlerts()`。連続赤字月数・悪化判定・大口集中の条件はここに集約しています。
- **ランキング件数** … `aggregate()` 内 `rank()` の `slice(0, 20)`。

## 制約

- 数値は**取り込んだCSVをそのまま集計した参考値**です。会計・税務の確定値としては会計帳簿と照合してください。
- 残高推移は**残高列がある明細のみ**。
- 1口座＝1系列です。複数口座の合算は対応していません（口座ごとに開いてください）。

テスト・Lint・ビルドはありません。
