# pension-planning-kit — 年金 × ライフプランニング資料

顧客にそのまま送れる、**A4・印刷/PDF対応の「年金プランニング資料」**（ゼロ依存の単一HTML）。日本年金機構「ねんきんネット」を入口に、「①現状を知る → ②将来を試算する → ③不足を埋めるプランを立てる」という**行動に落ちる**構成にしています。FP・金融リテラシー事業（例：株式会社ジャパンマネジメント）の営業・啓発ツールとして、配布・面談導入にそのまま使えます。

`construction-book` / `construction-portfolio` と同じ**ビルド不要の単一HTML**方式で、ブラウザ内で会社名・連絡先などを直接編集できます。

## 使い方

- ローカルで開く：`cd pension-planning-kit && python3 -m http.server 5183` → http://localhost:5183
  （`index.html` を直接ダブルクリックしてもOK。完全にクライアントサイドで動作します）
- **PDF/印刷**：右上ツールバー「🖨 PDF / 印刷で保存」→ ブラウザの印刷ダイアログで「PDFに保存」。A4・8ページで出力されます（A4 = 794×1123px @96dpi）。
- **文字の編集**：ツールバー「✎ 編集ON」を押すと、会社名・電話・URL・コピー等を直接クリックして書き換えられます。編集内容は `localStorage`（キー `pension_planning_kit_v1`）に自動保存。
- **初期化**：「↺ 初期化」で元に戻ります。

## 構成（A4 全10ページ）

1. **表紙** — 「将来を、数字で見える化する。」
2. **なぜ今か** — 漠然とした不安を“具体的な数字”へ（利用者数などの実データ付き）
3. **3ステップ** — 知る → 試す → 決める、の全体像
4. **STEP1 現状把握** — ねんきんネットの登録3方法（マイナ／アクセスキーあり／なし）とできること
5. **STEP2 将来試算** — かんたん試算／詳細試算、受給開始年齢（繰上げ・繰下げ）の比較
6. **STEP3 プランを立てる** — 不足を埋める4つのレバー（追納・繰下げ・iDeCo/NISA・就労/保険）
7. **年金の基本と数字（資料編）** — 2階建て構造・3種別の表・令和8年度の主要数字（保険料17,920円／満額847,300円／受給資格10年／所得代替率61.2%）
8. **こんなとき、どうする？（資料編）** — 退職・転職（14日以内）／短時間労働の適用拡大／免除・追納／任意加入・付加年金／在職老齢年金／障害・遺族年金
9. **Q&A** — 相談前によくある質問
10. **チェックリスト & 無料相談CTA** — 会社情報（編集可）

## 編集のポイント

- **会社情報は `data-k` 付き要素**（表紙・各フッター・CTAの連絡先など）。ブラウザ編集で書き換えられ、`localStorage` に保存されます。恒久的に既定値を変えたい場合は `index.html` 内の該当テキストを直接編集してください。
- **数値の扱い**：制度改正で変わる年金・税制の数値は本文中に `〔要確認〕` と明記しています。配布・面談前に、日本年金機構（nenkin.go.jp）・金融庁・国税庁等の最新情報で更新してください。
- **免責**：本資料は一般的な情報提供であり、個別の投資・税務・法務助言ではありません（各ページ下部およびP8に免責を記載）。

## 出典

いずれも日本年金機構の公式資料（令和8年度時点）を反映しています。

- 「ねんきんネットの概要」 — 利用者数の推移、登録方法、確認できる項目、試算機能、通知書のペーパーレス化 等
- 「国民年金・厚生年金保険 被保険者のしおり」 — 2階建て構造、被保険者の3種別、保険料額、免除・追納、給付額（老齢・障害・遺族） 等
- 「退職後の年金手続きガイド」 — 退職時の手続き（14日以内）、任意加入、繰下げ（最大84%増）、在職老齢年金、雇用保険との調整 等
- 「知っておきたい年金のはなし」 — 制度の考え方（社会保険方式・世代間扶養）、ライフステージと年金

金額・料率・要件は制度改正で変わります。配布・面談前に日本年金機構（nenkin.go.jp）・金融庁・国税庁等の最新情報で確認してください。

## メンテナンス

ビルド／テスト／Lint はありません（`echo-interview-console` / `construction-book` と同じ運用）。デザイン変更は `index.html` 内の `<style>`、文面変更は該当HTMLを直接編集します。
