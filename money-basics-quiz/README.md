# money-basics-quiz — 「お金の超基本」理解度チェック（金融リテラシー診断＆学習アプリ）

不動産経営者・営業向けの**金融リテラシー自己診断＆学習ツール**。配布教材「今更聞けないお金の超基本 理解度チェック問題集（全50問）」＋解説教材「金融リテラシー実践的ガイド」を、**ゼロ依存の単一HTML**（ビルド不要）に統合しました。50問をブラウザで出題→**自動採点**→**章別スコア**→**全問の解説付き復習**、さらに**学習（資料編）**で土台となる6テーマを読めます。UIは日本語。既定ブランドは株式会社 Martial Arts。

## 使い方

```bash
cd money-basics-quiz && python3 -m http.server 5186   # → http://localhost:5186
```

インストール・ビルド不要。`index.html` をブラウザで直接開いても動作します（完全クライアントサイド）。

- **ホーム**：出題範囲を選ぶ
  - **全50問に挑戦** … 6章通しで総合診断
  - **ランダム10問** … 50問から無作為10問のクイックチェック
  - **章別に挑戦** … 第1〜6章を個別に
  - **即時採点モード（トグル）** … ON＝回答直後に正誤＋解説を表示（学習向け）／OFF＝最後にまとめて採点（テスト向け）
- **結果画面**：総合正答率（リング）・判定ランク（S/A/B/C/D）・**章別正答率バー**・**全問の解答と解説**。`🖨 結果を印刷 / PDF保存` でブラウザの印刷ダイアログ→A4でPDF化。
- **学習（資料編）**：ガイドの6テーマ（重要性／家計管理・50/30/20／税金／インフレと金利／投資の3原則／向上とアクション）をアコーディオンで表示。

## 構成

- **すべて `index.html` に同梱**（markup＋CSS＋JS）。外部依存なし・ビルドステップなし（`echo-interview-console`／`construction-book` と同じ系統）。
- **`QUIZ` 配列が設問の単一の真実**：`{ch, q, text, opts:[4択], ans:0..3(a/b/c/d), exp:解説}`。設問を足す/直すときはここだけを編集。
- **`CHAPTERS`** … 章メタ（章番号・タイトル）。`STUDY` … 資料編の6テーマ本文。
- 採点・章別集計・復習リスト・判定ランク（`rankOf`）は純粋関数。前回結果は **localStorage**（キー `ma_money_quiz_v1`）に保存し、ホームに表示。
- ランダム出題は `shuffle()`（Fisher–Yates）。

## ブランド差し替え

ヘッダーとフッターの会社名は `data-k="co"` / `data-k="co2"` の要素、サブタイトルは `data-k="tag"`。別社向けにはこの3箇所を編集してください（配色は `:root` の `--gold` 系＝Martial Arts の白×金基調）。

## ファクト・ディシプリン（重要）

- 設問・解答・統計値は**配布教材の記載値に忠実**に転記しています（解答は教材の「解答一覧」と全50問一致することをスクリプトで検証済み）。
- **教材内の不整合はそのまま採点キーを優先**し、資料編に注記しています：
  - **問34**（日米金利差縮小→円相場）：解答一覧は「円高進行(a)」を正解。ガイド本文は「安定傾向」と記載 → 資料編第4章に注記。
  - **問45**（収支把握の推奨期間）：解答一覧は「1ヶ月(c)」。ガイドのアクションプランは「1週間」と記載。
- **税率・基礎控除額・NISA/iDeCoの制度枠・インフレ率**などは改正・変動があり、教材作成時点の参考値です。実運用前に**国税庁・金融庁・日本年金機構等の一次情報**で確認してください（問40のNISA枠には注記済み）。
- 本アプリは**金融教育・自己学習を目的とした情報提供**であり、特定の金融商品の勧誘・投資助言ではありません（各画面に免責を明記）。

## テスト/リント/ビルド

なし（この系統の他サブプロジェクトと同様）。動作確認はブラウザで直接。設問データの整合はリポジトリの検証スクリプト相当（全50問／各4択／解答キー一致）で担保しています。
