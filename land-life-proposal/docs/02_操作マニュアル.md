# 操作マニュアル — 戸建て所有シミュレーター

営業担当者が、お客様と並んでタブレットを見ながら使う前提の手順です。1回の商談で30〜60分が目安です。

## 0. 準備（商談前・5分）

1. `app/index.html` を開く（ネット接続は不要）。
2. 右上「保存・読み込み」→ 前回の案件があれば **ファイルから読み込む**。新規なら **サンプルに戻す**。
3. 提案物件の情報（価格・土地/建物の内訳・床面積・性能証明の有無・建築確認日）を手元に用意。
4. お客様に源泉徴収票の持参をお願いしておくと、住宅ローン控除を「詳細」で計算できます。

## 1. 商談の流れ（資料とシミュレーターの対応）

| 資料 | シミュレーター | ポイント |
|---|---|---|
| P01〜P03 憧れ | ― | 写真で暮らしをイメージしてもらう |
| P04 10年後の暮らし | ①お客様のこと（右側の4つの欄） | お客様の言葉をそのまま入力 → 提案書1ページ目に入る |
| P05〜P09 発見 | ③暮らしの優先順位 | スライダーで重みを選ぶと、賃貸／マンション／戸建ての順位が出る |
| P10 合う戸建て | ③物件に求める条件 | 「使う」「必須」と希望値を入れる → ⑩の適合チェックに反映 |
| P11 購入の全体像 | ④住宅ローン | 初期費用・毎月・手元資金の3つを必ず見せる |
| P12 支出の比較 | ⑥住まい方の比較 | マンションの条件は仮定値。地域の相場に合わせて入力 |
| P13〜P14 控除 | ⑤住宅ローン控除 | 上限と実際の見込みは別。概算か入力値かがバッジで出る |
| P15 10年総コスト | ⑥（控除あり／なしの切替） | 「控除の額だけで決めない」 |
| P16・P18 将来 | ⑧将来の売却 | 下落シナリオも必ず見せる |
| P19 収入減少 | ⑨収入が減ったら | 減少率は自由に変更できる |
| P20〜P21 | ②物件の情報（維持費・要件） | 維持費は仮定値。物件ごとに見積もりへ差し替え |
| P22〜P24 行動 | ⑩提案書 | 「提案書をPDFで出力」→ 印刷画面で「PDFに保存」 |

## 2. 各ステップの入力

### ① お客様のこと
- **世帯**：単身のまま使えば、子育て・若者夫婦世帯の上乗せは適用されません（既婚・19歳未満の扶養親族ありを選んだときだけ判定）。
- **税額**：「概算」は年収から推計。「詳細」では源泉徴収票の値を入れます。
  - 所得税額は**住宅ローン控除前・復興特別所得税を除いた額**（基準所得税額）。
  - 課税総所得金額等は、住民税から控除できる上限（×5%）の計算に使います。
  - 住民税所得割額は、住民税の決定通知書から。

### ② 物件の情報
- 金額は**万円**、割合は**%**で入力します（例：諸費用 7 → 7%）。
- **うち土地**：残りが建物価格になります（⑦の価値分析に使用）。
- **住宅性能区分**と「性能を証明する書類がある」：証明書がないと「その他の住宅」として判定されます。
- **建築確認日・登記上の建築日**：2028年以降入居の新築（省エネ基準）や、省エネ基準未満の新築の経過措置の判定に使います。中古は建築日で耐震要件（1982年以降なら証明不要）を判定します。
- **初年度の年末残高**：金融機関の返済予定表などで分かれば入力（空欄なら自動計算）。
- **暮らしの条件**：ハザードマップを確認するまでは「未確認」のままにしておきます（適合チェックで「？」と表示）。

### ⑤ 住宅ローン控除
- 緑の帯＝適用見込み、赤の帯＝適用なし（理由を表示）。注意事項は箇条書きで出ます。
- 「年ごとの明細」で、所得税から・住民税から・控除しきれない額を年ごとに確認できます。
- 「購入前に確認する書類」を開くと、その物件に必要な証明書の一覧が出ます。

### ⑩ 提案書
- 画面の提案書は、印刷すると**A4・3ページ**になります。
- Chrome / Edge：印刷 → 送信先「PDFに保存」→ 余白「なし」→「背景のグラフィック」にチェック。
- Safari（iPad）：共有 → プリント → ピンチアウトでPDFにして保存。

## 3. 保存と持ち出し

| 操作 | 内容 |
|---|---|
| この端末に保存（オン） | このブラウザに自動保存。共用端末では使わない |
| ファイルに書き出す | 案件ごとに JSON ファイルで保存（社内の決められた場所へ） |
| ファイルから読み込む | 書き出した JSON を開いて続きから |
| サンプルに戻す | 入力を初期値に戻す |

## 4. 困ったとき

| 症状 | 対処 |
|---|---|
| 数字が変わらない | 入力欄からカーソルを外す（選択肢・チェックは変更時に再計算） |
| 控除が「適用なし」になる | 赤い帯の理由を確認（証明書・床面積・建築確認日・入居年など） |
| 提案書の色が出ない | 印刷設定で「背景のグラフィック」をオン |
| 保存できない | プライベートブラウズでは保存できません。「ファイルに書き出す」を使う |

## 5. 守ること（営業トーク）

- 「必ず値上がりする」「絶対に損しない」「今買わないと損」は言わない（宅建業法の断定的判断の提供・不当な勧誘に当たるおそれ）。
- 控除は**見込み**。最大額を還付額として伝えない。
- 不利な数字（手元資金不足・返済負担25%超・売却時の持ち出し）こそ先に伝える。
- 次の一歩には、見送りも選択肢として示す。
