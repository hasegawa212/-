# スプレッドシート版　わかりやすさの設計

`tools/build-sheet.py` が作る「資金計画シミュレーター」を、**はじめて開いた人が1枚目だけで使える**形に作り直したときの設計メモ。

## 1. わかりにくかった点（前の版）

| # | 問題 | 起きていたこと |
|---|---|---|
| 1 | どこから見ればいいかわからない | タブが9枚並び、最初のタブは文章だけ |
| 2 | 入力が多すぎる | 入力シートに約45項目。ふだん変えない項目（審査の基準・控除の書類条件など）も同じ扱い |
| 3 | 結果に「だから何？」がない | 数字が並ぶだけで、良いのか悪いのかが書いていない |
| 4 | 数字が読みにくい | 28,900,000 のような円単位の大きな数字 |
| 5 | 計算途中の行が見える | 「制度の該当行の数」「経過措置の期限」、TRUE/FALSE が結果と同じ並びに出る |
| 6 | 言葉がむずかしい | 「控除対象の残高」「審査金利」など説明なし |

## 2. 方針

1. **1枚目＝「① かんたん試算」だけで完結**：入力 → 結果 → チェック → ひとことまとめ → グラフ を1画面に。
2. **入力は10項目前後に絞る**：年収・家賃・駐車場・預貯金・車などの返済・金利・年数、物件A/Bの名前・価格・頭金・区分。残りは「② 詳しい条件」（ふだんは変えなくてよい既定値）。
3. **結果には必ず判定をつける**：◎ 安心／△ 注意／× 要相談 を色つきで。判定の基準も同じ行に書く。
4. **単位を人の感覚に合わせる**：大きな金額は「万円」、毎月の金額は「円」、単位は数字の後ろに表示。
5. **計算途中は折りたたむ**：③ 詳しい試算 の計算用の行はグループにして閉じる（＋で開ける）。判定の要件は ○／× で表示。
6. **タブに番号と色**：①〜⑥が順番に見るもの、「参考：」は税率表など。色＝金（かんたん）・黄（条件）・紺（結果）・灰（参考）。
7. **計算式は変えない**：見せ方だけを変え、数値は `lib/engine.js` と一致し続ける（`tools/verify-sheet.py`）。

## 3. 画面の構成（① かんたん試算）

```
資金計画シミュレーター　＜会社名＞
使い方：① 黄色のマスに入力 → ② 結果とチェックを見る → ③ もっと詳しく：②〜⑥のタブ

STEP 1　あなたのこと        年収（万円）／家賃（円）／駐車場（円）／預貯金（万円）／車などの返済（円）
STEP 2　住宅ローン          金利（%）／返済年数（年）
STEP 3　くらべる物件        名前／価格（万円）／頭金（万円）／区分（新築・買取再販・中古）   … 物件A・物件B

結果                       今の賃貸｜物件A｜物件B｜この数字の意味
  毎月の住まいの支払い・うちローン返済・今の家賃との差
  はじめに必要な現金・手元に残る預貯金・住宅ローン控除（最初の10年）・10年間の住まいの費用
チェック                   返済の負担／ローン審査の目安／もしもの貯金／住宅ローン控除  → ◎△×
ひとことまとめ              物件ごとに1文
グラフ                     毎月の住まいの支払い（今の賃貸・物件A・物件B）
ご注意・会社情報
```

## 4. 判定の基準

| チェック | ◎ | △ | × |
|---|---|---|---|
| 返済の負担（年収比・車などの返済を含む） | 無理のない目安（既定25%）以内 | 審査の基準以内 | 審査の基準を超える |
| ローン審査の目安（審査金利で計算） | 基準以内 | — | 基準を超える |
| もしもの貯金（手元に残る預貯金） | 住居費＋生活費の6か月分以上 | 3か月分以上 | 3か月分未満 |
| 住宅ローン控除 | 対象（期間を表示） | — | 対象外（最初に満たさない要件を表示） |

## 5. できたかどうかの確認（受け入れ基準）

- 1枚目が「① かんたん試算」で、入力欄（黄色）は物件2件分を含めて15か所以下（前の版は約45か所）。
- かんたん試算の結果がエンジンと一致（`verify-sheet.py` に追加）。既存の228項目も一致のまま。
- どのシートにもエラー値・TRUE/FALSE の表示がない。
- Googleスプレッドシートに変換しても同じ値。
