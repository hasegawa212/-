# 人生を、自分の土地から。— 単身者向け 戸建て所有のご提案

**株式会社ジャパンマネジメント**｜営業提案資料（24ページ）＋ 対話型シミュレーター（Webアプリ）

ひとりで暮らす人が「戸建てを持つ意味」を理解し、数字で実現できるかを確かめたうえで、「実際に見てみたい」と思えるまでを、**憧れ → 発見 → 納得 → 安心 → 行動** の5幕で案内します。

---

| ファイル | 中身 | 使い方 |
|---|---|---|
| `人生を、自分の土地から。_JM提案資料.pptx` | 24ページ・16:9の提案資料。**各ページの発表者ノートに営業トーク**（伝えるメッセージ／質問／想定される不安／根拠に基づく回答／次ページへのつなぎ） | PowerPoint・Keynote・Googleスライドで開く |

| `営業トーク集.md` | 24ページ分の営業トークをまとめた台本 | 研修・ロールプレイ用 |

## シミュレーターを使う（インストール不要）

```text
app/index.html をダブルクリック（Chrome / Edge / Safari）
```

タブレットでも動きます。社内で共有するなら、フォルダごと置いて `python3 -m http.server 5190` → http://localhost:5190/app/ でも開けます。

**10のステップ**：①お客様のこと（10年後の暮らしを書き込む）→ ②物件の情報（2物件まで）→ ③暮らしの優先順位 → ④住宅ローン → ⑤住宅ローン控除 → ⑥住まい方の比較（賃貸・マンション・戸建て、控除あり/なし）→ ⑦土地・建物の価値 → ⑧将来の売却 → ⑨収入が減ったら → ⑩提案書（PDF出力）

入力するとグラフ・数字・下の要約バーがすぐ更新されます。操作の詳細は [`docs/02_操作マニュアル.md`](docs/02_操作マニュアル.md)。

### お客様情報の扱い

- 計算はすべて**端末の中だけ**。サーバーへの送信は一切ありません（`fetch` などの通信コードなし）。
- 保存は「保存・読み込み」で**オンにしたときだけ**このブラウザに残ります（確認ダイアログあり。オフにすると即削除）。
- 案件ごとに JSON ファイルへ書き出し／読み込みできます。共用端末では保存をオンにしないでください。

## フォルダ構成

```text
jm-house-proposal/
├── lib/                 計算（画面から独立・依存なし。Node でもブラウザでも動く）
│   ├── brand.js         会社情報（名前・電話・免許番号）← ここだけ直せば全体に反映
│   ├── rules.js         住宅ローン控除の制度データ（入居年ごと）← 税制改正時はここを更新
│   └── engine.js        ローン／税額の概算／控除／住居費／価値／売却／収入減少／比較／適合
├── app/                 対話型シミュレーター（index.html・app.js・style.css）
├── deck/build.js        24ページの資料を生成（数字は engine.js から）
├── test/engine.test.js  計算の検算（node --test）
├── tools/sample-proposal.js  サンプル提案書PDFを作る（任意・Playwright）
├── docs/                ストーリーボード・操作マニュアル・品質評価
└── dist/                成果物
```

## 作り直す・直す

```bash
cd jm-house-proposal
npm install                # 資料の生成に使う（pptxgenjs ほか）。シミュレーターだけなら不要
npm test                   # 計算の検算
npm run build              # dist/ の pptx と 営業トーク集.md を作り直す
npm run pdf                # pptx → PDF（LibreOffice）
node tools/sample-proposal.js   # サンプル提案書PDF（Playwright がある環境）
```

| 直したいこと | 直す場所 |
|---|---|
| 会社名・電話番号・担当者・免許番号 | `lib/brand.js` |
| サンプルの数字（年収・物件価格・金利など） | `lib/engine.js` の `SAMPLE` → `npm run build` |
| 住宅ローン控除の制度（改正時） | `lib/rules.js` の `RULES`・`COMMON` → `npm test` |
| スライドの文言・営業トーク | `deck/build.js`（各 `slide()` の第4引数がノート） |
| 写真 | `deck/build.js` の `photo()` の引数（写真は `../construction-portfolio/img/`） |

## 計算の考え方（すべて `lib/engine.js`）

- **住宅ローン**：元利均等。毎月返済額 ＝ 借入額 × r ×（1＋r）ⁿ ÷ {（1＋r）ⁿ − 1}。入居月に借入、翌月から返済。
- **住宅ローン控除**（基準日：2026年10月・2026〜2030年入居）：新築／中古／買取再販 × 認定・ZEH水準・省エネ基準・その他 × 入居年 × 建築確認日・建築日で可否と限度額・期間を判定。床面積・合計所得・返済期間・中古の耐震・取得先・入居時期・災害レッドゾーンも判定。各年の上限＝min（年末残高, 借入限度額, 取得価格）×0.7%。**所得税 → 翌年度住民税（5%・最高97,500円）の順に充当し、控除しきれない額は加算しない**。制度上の上限と実際の見込みを分けて表示。**子育て・若者夫婦の上乗せは単身者に自動適用しない**。
- **税額**：詳細モード＝源泉徴収票・住民税通知の値。概算モード＝給与所得のみ・社会保険料＝年収×料率で推計し、2028年以降も令和8・9年分の控除の特例が続くと仮定（税額を低めに見積もる保守的な前提）。結果に「概算」と表示。
- **価値と売却**：土地は年率（−1%／±0%／＋1%）、建物は10年後の残存割合（入力値 ±10ポイント、下限10%）の3シナリオ。売却手取り＝価格−仲介手数料の上限（税込）−その他10万円−残債。譲渡所得税は計算しない。
- **収入減少**：収入を減らしたときの手取りに対する返済・住居費の割合と、生活費を含む毎月の余裕、不足する場合に手元資金が何か月もつか。

出典：財務省「令和8年度税制改正の大綱」、国土交通省「住宅ローン減税」、国税庁 タックスアンサー No.1211-1／1211-2／1211-3。

### 〔要確認〕のまま残っているもの

- 買取再販住宅の借入限度額（新築に準じて計算）
- 住民税から控除できる上限（5%・97,500円）が2026年以降の入居でも同じか
- `lib/brand.js` の電話番号・営業時間・宅地建物取引業の表示（物件の紹介・仲介を行う場合）

## 今回実装していないもの

| 依頼にあった構成 | 今回の判断 |
|---|---|
| Next.js・React・TypeScript・Tailwind・Recharts | 「見るのも作るのもわかりやすく」を優先し、**ビルド不要の HTML＋JavaScript** にしました（ダブルクリックで動く／直すのもファイル1つ）。計算は `lib/` に分離済みなので、将来 Next.js に移すときもそのまま使えます |
| PostgreSQL・Prisma（データ保存） | 未実装。保存は端末内（任意）と JSON ファイルのみ |
| 認証・アクセス権限・通信暗号化 | 未実装。**お客様情報をサーバーに置かない設計**にしたため不要にしています。複数担当者で案件を共有する段階で、サーバー・DB・認証とセットで実装が必要です |
| 写真 | 実在の戸建て写真（`construction-portfolio/img/`）を「イメージ写真」と明記して使用。提案する実物件の写真は物件ごとに差し替えてください |
