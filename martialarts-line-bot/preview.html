このビジネスラインでできること

  • 友だち追加でブランドのウェルカムカードを自動送信
  • 6事業を横スクロールのカルーセルで一覧・詳細表示
  • 売却査定 / 購入 / 建築 / 太陽光 / 設備 / 保険をキーワード自動応答
  • 連絡先・アクセスは電話・地図ワンタップのカードで
  • 下部のリッチメニューで、文字入力なしでも主要導線へ

「最強に便利」の設計

  • 入力が苦手な人 → リッチメニューをタップ
  • ざっくり聞きたい人 → 自由入力でOK（部分一致）
  • 急ぎの人 → どの画面からも電話ボタン
  • 遠方の人 → オンライン相談を案内

すぐ試す（ローカル）

npm install && npm run dev
GET /dev/simulate?text=査定 で応答を確認（LINE不要）。

※ このプレビューは実際の送信JSON（flex.js）を忠実にHTML再現したものです。実機のLINEでも同じレイアウトのFlexメッセージが表示されます。電話番号など〔要確認〕は公式情報に差し替えてください。
