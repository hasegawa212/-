# iPhone マウス（PhoneMouse）＋ 照準ゲーム「Halo Burst」

iPhone を **Mac のマウス**にする。通信は **Bluetooth（BLE）だけ**。サーバーも Wi-Fi も不要。

```
iPhone（PhoneMouse アプリ）  ──BLE notify 8バイト──▶  Mac（PhoneMouseMac）──CGEvent──▶ 本物のカーソル
  タッチ / ジャイロ                                      クリック・ドラッグ・スクロール
```

| フォルダ | 中身 |
|---|---|
| `ios/PhoneMouse.swiftpm` | iPhone アプリ（SwiftUI + CoreBluetooth + CoreMotion）。Xcode で開くだけでビルドできる App パッケージ |
| `mac/` | Mac の受信アプリ（Swift Package・コマンドライン）。届いた入力を本物のマウスイベントにする |
| `game/` | 動作確認用の照準ゲーム **Halo Burst**（ブラウザで開くだけ） |

## 操作

**トラックパッド モード** — 1本指でなぞる＝移動（速く動かすほど遠くへ）／タップ＝クリック／長押し→動かす＝ドラッグ／2本指＝スクロール／2本指タップ＝右クリック

**エアマウス モード** — 画面を上にして iPhone の上端を Mac に向け、手首を振る＝カーソル移動（ジャイロ）／タップ＝クリック／押しっぱなし＝ドラッグ／2本指タップ＝右クリック

画面下の「左クリック」「右クリック」は押している間ずっと押下（ドラッグにも使える）。感度スライダーと最後のモードは保存される。

## 動かし方（10分）

必要なもの: Mac（macOS 12+）、Xcode 15+、iPhone（iOS 16+）、Apple ID（無料でOK）

### 1. iPhone アプリ
1. Xcode で `ios/PhoneMouse.swiftpm` を開く（Finder でダブルクリック）
2. Signing & Capabilities の Team に自分の Apple ID を選ぶ（必要なら Bundle Identifier を `com.自分の名前.phonemouse` などに変更）
3. iPhone をつないで ▶ Run。初回は iPhone の 設定 › 一般 › VPNとデバイス管理 で開発元を「信頼」
4. 起動して Bluetooth の利用を「許可」→「Mac を待っています…」になれば準備完了

### 2. Mac の受信アプリ
```bash
cd mac
swift run -c release
```
- 初回だけ **アクセシビリティ** の許可を求められる → システム設定 › プライバシーとセキュリティ › アクセシビリティ で、起動元（ターミナル など）をオンにして起動し直す
- **Bluetooth** の許可も求められたら「許可」
- 「接続しました」と出たら、iPhone でカーソルが動く。終了は Ctrl+C（切断すると押しっぱなしのボタンは自動で離す）

### 3. ゲームで遊ぶ
`game/index.html` を Mac のブラウザで開く → クリックでスタート、F で全画面。
縮んで消える前にリングを撃ち抜く。中心 ×2、金のリング ×3、5連続ごとにコンボ倍率 +1（最大×5）、外す/逃すとコンボが切れる。60秒勝負、ベストはブラウザに保存。

## 仕組み（要点）
- iPhone が **BLE ペリフェラル**としてサービス `6E1B0001-…` を広告し、Mac が **セントラル**として接続・購読する。iOS は標準の HID（マウス）プロファイルを名乗れないため、Mac 側に小さな受信アプリが要る。
- パケットは 8 バイト固定（`Protocol.swift`）: ボタン状態 / dx / dy / scroll（Int16, LE）。ボタンは「状態」を送り、Mac が差分で押す/離すを作るので、取りこぼしても押しっぱなしになりにくい。
- iPhone は 60Hz で移動量をまとめて送り、端数は次回へ持ち越す。送信バッファが一杯のときは移動だけを合算し、ボタンの変化は必ず順番どおり届ける。
- Mac は `CGEvent` で移動・クリック（ダブルクリック判定つき）・ドラッグ・ピクセル単位スクロールを流す。移動量（delta）も入れるので、ポインタロックを使うブラウザゲームでも動く。カーソルは全ディスプレイの範囲内に収める。
- 接続遅延は `setDesiredConnectionLatency(.low)` で最小に要求。

## テスト
```bash
npm test   # iPhone/Mac の通信仕様が同じか・パケットの往復・ゲームの得点ルール
```
Swift のビルドは macOS + Xcode が必要（このリポジトリの CI では行っていない）。`Protocol.swift` は iPhone と Mac で**同じ内容に保つ**こと（テストで確認）。

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| Mac が「探しています…」のまま | iPhone アプリを前面で開いておく／iPhone の Bluetooth をオン／Mac 側を再起動 |
| 接続したのにカーソルが動かない | アクセシビリティの許可（起動元アプリ）をオン → 起動し直す |
| `swift run` で Bluetooth 許可が出ない/落ちる | システム設定 › プライバシーとセキュリティ › Bluetooth で起動元を許可 |
| エアマウスが流れる | iPhone を机に置いて数秒静止（ジャイロの補正）／感度を下げる |
