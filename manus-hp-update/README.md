# Manus AI ホームページ修正プロンプト集

Manus AI で作成した格闘技マネジメント協会のホームページに対する、修正指示プロンプトをまとめたドキュメント。
Manus AI にそのまま貼り付けて使えるよう整理してある。

- **今回の即時修正** → 下記「① HP修正プロンプト」をコピペで使用
- **今後の活動計画（構想・メモ）** → 「② 今後の活動計画メモ」に整理（HP修正とは分離）

> なぜ分けるか: 構想メモまで1つのプロンプトに混ぜると、Manus が未確定の計画まで勝手にページ化してしまい収拾がつかなくなるため。②が実行段階に入ったら、その都度 **別プロンプト**（協会紹介ページ追加用 / SNS運用ページ用 等）として切り出す。

---

## ① HP修正プロンプト（コピペ用）

```
現在のホームページに、以下の修正を加えてください。デザインの世界観・レイアウト・トーンは今のまま維持し、指定した箇所だけを変更してください。

【1】「Manus」表記の削除
- ページ内・フッター・メタ情報・クレジットなど、「Manus」「Manus AI」「Made with Manus」等の表記があればすべて削除してください。
- 削除により空白や不自然な余白が出た場合は、レイアウトを自然に詰めてください。

【2】「Logan Story（ローガンストーリー）」セクションの削除
- ローガン選手のストーリーに関するセクション／ブロックをページから丸ごと削除してください。
- 前後のセクションが自然につながるよう間隔を調整してください。

【3】選手写真の追加：後藤丈二 選手
- 選手紹介セクションに「後藤丈二（Goto Joji）」選手を新しいカードとして追加してください。
- 写真は仮のプレースホルダー画像を配置し、後から差し替えられるようにしてください（画像の差し替え箇所が分かるようにコメントまたはラベルを付けてください）。
- 名前・階級・戦績などのテキスト欄も、他選手カードと同じフォーマットで用意してください（値は仮でOK、後で編集できる形に）。
- 今後さらにファイトキャンプ参加選手を追加していく予定なので、選手カードは簡単に増やせる構造（グリッド／繰り返しレイアウト）にしてください。

【4】SNSリンクの設置
- ヘッダーまたはフッター（もしくは両方）に、公式SNSへのアイコンリンクを追加してください。
  - Instagram
  - TikTok
  - X（旧Twitter）
- リンク先URLは仮（#）で構いませんが、後からURLだけ差し替えられるよう、各リンクに分かりやすい印を付けてください。
- アイコンは現在のサイトのデザインテイストに合わせてください。

【共通の注意】
- 上記4点以外は一切変更しないでください。
- 変更後、各修正が反映されているかを一覧で報告してください。
- 差し替え予定の箇所（後藤選手の写真、SNSのURL）は、後から非エンジニアでも編集できるよう場所を明記してください。
```

### 修正内容サマリー（クライアント依頼の対応表）

| # | 依頼 | 対応 | 優先度 |
|---|------|------|--------|
| 1 | マヌスを消す（消せれば） | 「Manus」表記をすべて削除 | 即時 |
| 2 | ローガンストーリーを外す | 該当セクションを丸ごと削除 | 即時 |
| 3 | 後藤丈二選手の写真 | 選手カードを追加（写真は差し替え式） | 即時 |
| 4 | SNSのページを貼る | Instagram / TikTok / X リンク設置 | 即時 |
| 5 | 他ファイトキャンプ選手の追加 | カードを増やせる構造にしておく（追加は追々） | 追々 |

### 差し替え待ちの確定情報（判明したら実値に更新）

- **後藤丈二 選手**: 写真 / 階級 / 戦績（現状は仮テキスト）
- **SNS URL**: Instagram / TikTok / X の各公式アカウントURL（現状は `#`）
