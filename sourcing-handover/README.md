# 仕入れ引き継ぎコンソール

2026/9/24 の仕入れ引き継ぎ（長谷川徹さん → 藪＋CEO）を、**紙の質問票で終わらせず、回答と実績をその場でデータにする**ための単一HTMLツール。ゼロ依存・ビルド不要（`construction-book` / `sales-org-1on1` と同じ系統）。

## 使い方

```
cd sourcing-handover && python3 -m http.server 5187   # → http://localhost:5187
```

`index.html` を直接ブラウザで開いても動く（完全クライアントサイド）。URL の `#q` / `#c` / `#o` で直接そのタブを開ける。

## 3つのタブ

### ① 質問シート
`引き継ぎ質問シート_詳細版_20260924.md` の **61問（A〜G）をそのまま画面化**したもの。回答を打つと自動保存、回答済みの問は番号が緑になる。

- 絞り込み：**全部 / 最優先 A・B・C / 未回答のみ** ＋ キーワード検索
- セクションごと・全体の進捗バー（最優先34問の消化率を別表示）

### ② 実績カウント
5月以降に出した物件を1行ずつ入れると、**どの段で落ちているかを自動集計**する。

`出した → 徹さんOK → 買付提出 → 審査申込 → 審査通過 → 決済済` のファネルを、件数・前段比・全体比で表示。NG/否決/停止の理由も一覧化される。**NGと言われた物件も必ず入れる**（それが分母）。CSVの読み書き可（`物件出し実績カウント_2026年5月以降.csv` と同じ列）。

### ③ 出力
回答が入っている項目だけを整形して **マニュアル反映用の Markdown** を生成（未回答は「次回持ち越し」として末尾に列挙）。コピー / `.md` 保存 / JSONバックアップ / 印刷・PDF。

## データの置き場所

**localStorage のみ**（キー `ma_sourcing_handover_v1`）。サーバーには何も送らない。別のPCで続けるときは ③ の JSON書き出し → 読み込み。顧客名は**イニシャルのみ**で入力すること。

## 中身をいじるとき

- **質問を足す / 直す** → `index.html` 冒頭の `QUESTIONS` 配列。`引き継ぎ質問シート_詳細版_20260924.md` の表から機械的に生成したものなので、**md 側を直したら同じ形で反映する**（id は `A-1` 形式、`sec` はセクション記号）。
- **ファネルの段を変える** → `STAGES`（ラベルと判定関数の組）。
- **テーブルの列を変える** → `COLS`（キー・見出し・型。配列を渡すと select になる）。CSV の列名は見出しと同じ。

## 関連ファイル

`経営管理/07_業務管理/業務マニュアル/仕入れ・案件管理/` に、元になった資料一式（質問シート詳細版・事前共有・ヒアリングシート・実績カウントCSV・物件仕入れマニュアル）が md と PDF で置いてある。

研修後は ③ の出力を `物件仕入れマニュアル_再現性版.md` に反映し、特に **C（基準値）を★ステップ2の条件表に数字で入れる**こと。
