# lifeplan-home-kit — マイホーム × 年金 ライフプラン資料

不動産・建設事業（株式会社 Martial Arts 等）が顧客に配布できる、**A4・印刷/PDF対応の「住宅×年金×資産」ライフプラン資料**（ゼロ依存の単一HTML）。「賃貸か購入か」で終わらせず、**住宅ローン・団信・住宅ローン控除・公的年金・資産形成（iDeCo/NISA）**までを一本のライフプランでつなぎます。

`pension-planning-kit` が年金中心の資料なのに対し、こちらは**マイホーム購入を軸に、老後（年金）まで見据えて資産設計する**視点でまとめた、不動産営業・住宅相談向けの姉妹資料です。年金の数字は日本年金機構の公式資料（令和8年度）に基づきます。

`construction-book` / `construction-portfolio` / `pension-planning-kit` と同じ**ビルド不要の単一HTML**方式で、ブラウザ内で会社名・連絡先などを直接編集できます。

## 使い方

- ローカルで開く：`cd lifeplan-home-kit && python3 -m http.server 5184` → http://localhost:5184
  （`index.html` を直接開いてもOK。完全にクライアントサイド動作）
- **PDF/印刷**：右上「🖨 PDF / 印刷で保存」→ ブラウザ印刷で「PDFに保存」。A4・10ページで出力（表紙＋本編9）（A4 = 794×1123px @96dpi）。
- **文字の編集**：「✎ 編集ON」で会社名・電話・URL・コピー等をクリック編集。`localStorage`（`lifeplan_home_kit_v1`）に自動保存。「↺ 初期化」で復元。既定は閲覧モード。

## 構成（A4 全10ページ／表紙＋本編9）

1. **表紙** — 「住まいから始める、生涯の資産設計。」
2. **人生の3大資金** — 住宅・教育・老後を一枚で見渡す／収入は年金に切り替わる
3. **賃貸 vs 購入** — 生涯コストと「老後の住居費」で比べる
4. **資金計画** — 頭金・諸費用・返済負担率／「借りられる額」より「返せる額」
5. **住宅ローン** — 金利タイプ／団信＝保険／住宅ローン控除／繰上げ返済
6. **老後の土台＝年金** — 令和8年度の数字（満額847,300円・所得代替率61.2%・繰下げ84%増）＋“完済した住まい”の効果
7. **資産形成** — マイホーム＝住まい・資産・保険の三役／iDeCo・NISA／「返す」か「増やす」か
8. **ねんきんネット** — まず自分の年金額を知る（登録3方法・試算・最大5件比較）
9. **年代別チェック & Q&A** — 20〜30代/30〜40代/50代〜＋よくある質問
10. **無料相談CTA** — 相談前の3ステップ、会社情報（編集可）

## 編集のポイント

- **会社情報は `data-k` 付き要素**。ブラウザ編集で書き換えられ `localStorage` に保存。既定値を恒久的に変えるなら `index.html` の該当テキストを直接編集。既定ブランドは **株式会社 Martial Arts**（不動産・建設）。
- **数値の扱い**：確定している令和8年度の年金額は明記。住宅ローン控除・iDeCo/NISA枠・頭金/諸費用/返済負担率の目安など、制度改正や物件・金融機関で変わる項目は `〔要確認〕` を明記し、各ページ下部＋最終ページに免責を記載。
- **レイアウト注意**：`賃貸 vs 購入` は3カラム（`.vs`）。印刷（A4=794px）で横並びを保つため、モバイル用ブレークポイントは `@media screen and (max-width:760px)`（ページ幅794pxより小さく、印刷には効かない）にしています。

## 出典（年金データ）

いずれも日本年金機構の公式資料（令和8年度時点）：「ねんきんネットの概要」「国民年金・厚生年金保険 被保険者のしおり」「退職後の年金手続きガイド」「知っておきたい年金のはなし」。住宅ローン控除・頭金・諸費用・返済負担率等の目安は一般的な水準で、年度・物件・金融機関により変わります。配布・面談前に日本年金機構（nenkin.go.jp）・金融庁・国税庁等の最新情報で確認してください。

## メンテナンス

ビルド／テスト／Lint なし。デザインは `index.html` 内の `<style>`、文面は該当HTMLを直接編集します。
