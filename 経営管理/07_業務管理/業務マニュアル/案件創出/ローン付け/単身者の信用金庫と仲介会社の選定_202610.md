## 2. 「通るか」の見方

- **決めるのは金融機関と保証機関。** 上の表は「当社の単身のお客様で、ここまで進んだ」という実績で、承認の約束ではない。
- 営業報告ログには進んだ案件しか残っていない。否決の件数は残っていないので、**通過率はこのデータからは出せない。** 否決の記録は、銀行審査状況パイプラインの否決タグ（`borrower_single` など）で残し、次回この表を更新する。
- 信金で通りやすいお客様（社内の記録から）:
  - 地元に勤める会社員で、勤続が安定している
  - 物件が地元にある
  - 転勤・転職・引っ越しが少ない
- 信金で止まりやすいお客様:
  - 勤務先の情報が食い違う（雇用契約書を求められる）
  - 源泉徴収票の住所が何度も変わっている
  - 転勤の予定、地元に戻る予定がある → 住宅ローンの前提（自分が住む）が崩れるので、申し込まない

## 3. 仲介会社を選ぶときのルール

- **当社が売主であること、仲介会社がグループ会社であることは、隠さずに伝える。** 銀行事前申込対応マニュアルの3章にあるとおり、銀行と保証会社は「売主・買主・業者の関係」を必ず見ている。後から分かると、その銀行との関係そのものを失う。
- 引き継ぎ記録に「Martial Arts の名前が出ると受付されない銀行がある」とあるが、**名前を出さないために仲介や売主を立てる組み方はしない。** そのような銀行は候補から外し、ほかの銀行に出す。
- 仲介会社は次の順で選ぶ。
  1. その信金の、その支店での実績がある
  2. 物件と同じエリアで重要事項説明ができる
  3. 信金がだめだったとき、同じ仲介で次の候補に出せる
  - この3点をすべて満たすのは増子建設

## 4. 単身者で出すときの準備（信金向け）

| 準備 | なぜ必要か |
| --- | --- |
| **購入動機書**（なぜこの土地に住み続けるのか。勤務先・地元・将来の計画） | 保証機関は単身者の戸建て購入の動機を必ず聞く。社内の実例でもこの書面で通している |
| 在籍証明書・就業条件明示書（雇用契約書の代わり） | 勤務先の情報が食い違って止まった例がある |
| 他の借入のおまとめ・完済の計画 | 車・カードのおまとめが条件になった例がある。承認後は借入を増やさない |
| 返済期間の設計 | 返済比率が厳しいときは長期で組む（鹿沼信金では50年で返済比率をクリアした例がある） |
| 出資金（会員加入） | 信金は一定額を超える借入で会員になる。社内では出資金1万円を当社が持参した例がある。金額は金庫に確認する |
| 本人確認電話の事前案内 | 保証機関から本人に電話が入る。知らない番号に出ないお客様には先に伝える |

## 5. 申込みの順番

- **原則は1案件に1行。** 否決されたときだけ次の行に出す（銀行マスタ運用ルール7章）。同時に申し込むと、申込情報が信用情報に残る。
- 申込みの順番:
  1. 1章の第一候補の信金
  2. 同じエリアの次の候補（労金・地銀・JA）
  3. それでもだめなら、2章の「止まりやすい」理由を直してから出し直す
- 信金は、事前審査と本審査がそれぞれ1〜2週間、全体で約4週間かかる（仕入れ会議運営マニュアル）。決済月が決まっている場合は、前月末までに物件を決めて本申込みまで進める。
