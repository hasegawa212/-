## C. 物件チェックの「基準値」を数字にする

> 現状の課題：④物件情報確認が**「販売図面に書いてある事項の確認」で止まっている**。土地面積・建物面積を見てはいるが、**「何㎡以上なら評価が付く」という足切りの数字が無い**。だから謄本やネットで誰でも取れる情報の確認になっていて、選別になっていない。ここを数字で埋める。

| # | 質問 | 回答欄 |
| :-- | :-- | :-- |
| C-1 | **土地面積**：これ未満は評価が付かない／扱わない、という下限は？（エリア別に違うか） | |
| C-2 | **建物面積**：同上の下限。延床何㎡以上か | |
| C-3 | **築年**：社内は「基本20年以内」。例外を認める条件は？（ハウスメーカー・リフォーム済 等） | |
| C-4 | **地勢**：ひな壇・傾斜地・造成地は銀行がどう見るか。どのレベルから避けるか | |
| C-5 | **地目**：宅地以外（畑・雑種地等）はどこまで許容するか。変更にかかる時間 | |
| C-6 | **接道・私道**：私道の持分なし／通行掘削の承諾書なしは即撤退か。幅員の下限 | |
| C-7 | **再建築不可**：例外なくNGでよいか（融資が出るケースはあるか） | |
| C-8 | **リフォーム歴**：どの範囲のリフォームが担保評価に効くか。効かないリフォームは | |
| C-9 | **告知事項**：許容できるもの／即撤退のもの（事件事故・雨漏り・基礎） | |
| C-10 | **所有権／借地権**：借地はどういう条件なら扱えるか | |
| C-11 | **（マンション）管理費・修繕積立金**：月額いくらを超えると返済比率を圧迫してNGか | |
| C-12 | 長谷川徹さんが物件を見て**一番最初に見る項目トップ3**は？（順番も） | |

→ **回答は `物件仕入れマニュアル_再現性版.md` の ★ステップ2 条件表／★ステップ0 ④ に数字で反映する。**
