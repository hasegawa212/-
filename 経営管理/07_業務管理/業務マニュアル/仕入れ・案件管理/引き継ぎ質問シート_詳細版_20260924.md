# B. 「どこまで言っていいか」の線引き【最優先】

> ここが今、現場で一番言葉が止まっているところです。会社に不利になるのではと思って言えず、結果として濁した返事になっています。**「ここまでは言っていい」の線**を引いていただけると、そのまま動けるようになります。

| B-2 | 答える場合、具体的にどう言いますか（そのまま使える言い方で） | |
