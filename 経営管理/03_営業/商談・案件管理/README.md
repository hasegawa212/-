# 商談・案件管理

営業報告ログ（Slack の報告一覧）と利益表を突き合わせ、**案件がどこで止まっているか**と**それがいくらの利益になったか**を1枚で見るためのボードです。

## Google スプレッドシート版

同じ内容をスプレッドシートにしたものがあります（サマリー／案件一覧／報告ログ／月次利益／9月パイプラインの5タブ）。

https://docs.google.com/spreadsheets/d/1SuIWhSRPwXRmKWHcI6osmaW4waCPPtyC8Hg1dT980bM/edit

案件一覧・報告ログにはフィルタが付いています。案件一覧は状態（要再確認／停滞／完了）で行に色が付き、月次利益は収支がマイナスの月が赤くなります。手で編集して構いませんが、`raw.txt` からの再生成で上書きされるわけではないので、恒久的な修正は下記の再生成フローで元データ側に入れてください。

## 見かた

```
cd 経営管理/03_営業/商談・案件管理
open 案件進捗ボード.html          # そのまま開く。python3 -m http.server でも可
```

- 棒・行にカーソルを合わせると内訳が出ます（キーボードの Tab でも同じ）。
- 「稼働中案件」は列見出しクリックで並べ替え、上のボタンで絞り込みできます。
- 印刷ダイアログ →「PDFとして保存」で A4 配布版になります（操作ボタンは印刷時に消えます）。

## 更新のしかた

数字の出どころは3つです。増えたぶんを追記して再生成します。

1. 報告が増えたら `raw.txt` に1行足す（`No|日付|報告種別|お客様名|売主|仲介|金融機関|担当|同行①|同行②|次回予定|日時|報告者|備考`）
2. 月次の利益・私募債は `profit.json`、当月の案件別内訳は `sep9.json` を更新
3. 再生成：

```
node norm.mjs && node build.mjs && node csv.mjs   # out/ に出力 → このフォルダへコピー
```

`norm.mjs` が正規化の単一の置き場所です。お客様名の表記ゆれ（`NAME_FIX`）、担当者の役職ゆれ（`OWNER_FIX`）、Slack のテンプレート文字列の除去（`clean` / `cleanPlan`）、ステージ定義（`STAGE`）はすべてここにあります。ステージを増やす場合は `build.mjs` のファネル・ラベル配列も合わせて直してください。

## 集計ルール（読むときの前提）

- **ステージ順**：事前承認 → 契約完了 → 本承認 → 金消契約 → 決済完了 → 案件完了。案件のステージは「到達した最上位」で判定します。
- **案件の分け方**：同一顧客でも、決済完了・案件完了のあとに新しい報告が始まったら別案件（案件2）として分離します（池田好希・小池雅広が該当）。
- **経過日数**：実日付ではなく **データ最終日 2026-08-21** 基準です。ログを追記したら基準日も自動で動きます。
- **金額**：原本どおり万円単位。報告ログから機械的に導出した参考値で、会計上の確定値ではありません。

## 個人情報の扱い

顧客台帳の **年収・勤務先・預金額・与信/否決履歴はこのフォルダに一切含めていません**（ランク別・担当者別などの集計値のみ利用）。同種の項目を後から持ち込まないでください。お客様名・金融機関・担当者はボードの用途上そのまま入っています。外部共有する場合は先に匿名化してください。
