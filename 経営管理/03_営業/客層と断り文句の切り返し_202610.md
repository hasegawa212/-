## 3. 切り返しの型（全員同じ）

**① 受け止める → ② 聞く → ③ 事実（お客様の数字・資料）で返す → ④ 小さな次の一歩**。各断り文句の具体的な言い方は早見表（`objections.html`）にあります。要点だけ：

| 断り文句 | ② 聞く | ③ 事実で返す | ④ 次の一歩 |
|---|---|---|---|
| 不信感 | どんな話なら聞いてもいいか | 会社名・目的（商品も扱う）を最初に。HPを見せる。売り込みなし・30分・録音OK | 自宅以外で30分。SMSで予定を送る |
| 今は必要ない | 10年後・30年後どう暮らしたいか | 「整理するだけ」。シミュレーター⓪（生涯収入と住まいの割合） | 30分の整理。要否は本人が決める |
| 忙しい | シフトが出るのはいつか | オンライン30分も可 | シフトが出る日に連絡＋仮日程 |
| 第三者 | 何を心配されていたか | 会社の資料を家族にも | 心配している人の同席 |
| 転勤 | 決まるのはいつ・範囲は | 待つのも選択肢（⑦で待つコスト）。買うなら売る・貸すがしやすい立地。事前審査は先にできる | 内示の時期に連絡＋事前審査 |
| 今はいい | 待つ理由・その理由がなくなるのはいつ | ⑦：1・3・5年待つと家賃・完済年齢・65歳以降の返済がどう変わるか | 「借りられるか」だけ確認／再開のきっかけを決める |
| 家族の反対 | 一番の心配は何か | 心配ごとに数字と選択肢。パートナーの希望を条件に | 決める人の同席 |
| 借金が怖い | 毎月いくらなら安心か | 家賃と並べる・返済比率・団信・③④ | 「毎月○万円以内」を決めてその範囲だけ |
| 社宅・補助 | 補助はいつまでか | 補助が終わった後の家賃と②一生の住居費。続く間は貯金・NISAも合理的 | 補助が終わる1年前に再度 |
| NISA優先 | 住まいは一生賃貸の予定か | 住まいは投資の代わりではなく「一生の住居費の払い方」。⓪と⑥（公平な比較） | NISAは続けたまま住居費だけ比較 |
| 話が違う | どこまでなら聞いていいか | まず謝る。商品の話をするかはお客様が決める | 次回の目的を書いてSMS |

**実際にうまくいった例（Slackより）**
- 「買うかどうか」ではなく「金融機関で進められるかを確認しましょう」→ 「99.9%断る」と言っていたお客様が事前審査へ。事前審査は無料で購入の義務がないことを伝えた。
- パートナーの希望（築浅・エリア）を条件に入れて内見写真を共有 → 「このエリアなら買ってもいい」→ 事前申込。
- 賃貸と持ち家の比較を本人に調べてもらい、質問に答えてから決めてもらう。NISA・投資不動産・現金の3択を本人に選ばせる。
- 「聞いて良いと思ったら取り入れてください」と伝えたら警戒がとけた。家に入れたくない人はファミレスに変更。

## 4. 失敗パターン（ここを減らすと数字が上がる）

1. **アポで目的をぼかす**（アンケート・FPの話だけ）→ 商談で「話が違う」→ 不信感・打ち切り。最初から「住まいとお金の相談。商品も扱う会社」と伝えるほうが、商談の前進率は上がる。
2. **前日確認が取れないまま当日を迎える**（キャンセル・不在の約半分）→ アポの場でSMS・LINEの連絡先を取り、お礼SMS→前日→当日の3回確認。
3. **玄関先で日時だけ切る**（関係が浅い）→ C帯に集中し、飛ぶ。最低限のヒアリング（勤務・家族・住まいの予定）をしてから日時。
4. **決める人がいない場で決めさせようとする** → 親・彼女の反対で打ち切り。初回から同席を提案。
5. **条件を整理しないまま内見を重ねる**（10回以上の例）→ 絶対条件3つを先に決める。
6. **キャンセル巻き（断りの撤回交渉）**はほぼ成功していない → 引くときは引き、再開のきっかけ（内示・結婚・補助終了・貯金）を約束して終える。
7. **ボイレコを録らない**（直ドア・冒頭で切れる）→ 振り返りができない。

## 5. やってはいけないこと（会社を守るため）

- **「今しか買えない」「今買わないと損」と思わせる**（宅建業法の「断定的判断の提供」・威迫にあたるおそれ）。管理者の指示で「今が1番ベストで今しか買えない認識を持たせる」という表現があったが、**お客様の数字で待つコストを見せる**（シミュレーター⑦）に置き換える。
- **住宅ローンで買って、住むのは異動の後**（住宅ローンは本人が住むことが条件。守れない計画は勧めない）。
- **キャッシュバックを契約書・金融機関に開示しない**（融資の申告と食い違うおそれ。必ず書面に残し、金融機関にも伝える）。
- 断られた後の過度な電話・張り込み・訪問（「警察を呼ぶ」まで悪化した例あり）。
- 「家賃は無駄」「必ず値上がり」「返済はすべて資産」「NISAより必ず有利」。

## 6. Slackの情報管理で気になった点（要対応）

- #09 に**お客様の氏名・住所・電話番号が平文で多数**投稿されている。#02 の見込み報告にも電話番号・住所の生データがある。
- #03 に**Zoom録画リンクがパスコード付き**で投稿されている。
- 物件選定ボットが**当社の利益の目安をお客様名と並べて**投稿している。

→ 公開チャンネルなので、閲覧範囲の見直し（非公開化）、個人情報はイニシャル・顧客IDに置き換え、録画リンクは期限付き・パスコード別送、を推奨します。
