# 商談ヒアリング分析（hearing-risk-analyzer）

Slack の **#03_商談報告** をそのまま貼り付けると、ヒアリングから **将来のリスク** と、それぞれに対する **不動産の価値の伝え方**・**次回の確認事項**・**次にやること** を出す社内ツールです。依存なし・ビルド不要・通信なし。

## 使い方

```text
index.html をダブルクリック（Chrome / Edge / Safari）
→ 左に商談報告を貼り付け → 「分析する」
→ 「Markdownをコピー」で Slack や社内メモへ／「印刷・PDF」で紙に
```

コマンドで使う場合：

```bash
node tools/analyze.js 商談報告.txt > reports/分析.md   # reports/ は .gitignore 済み
npm test                                            # 18件
```

## 断り文句の切り返し（`objections.html`・`lib/objections.js`）

Slack（#02 アポ報告・#09 キャンセル・#03 商談報告・#18 ボイレコ、2026年9〜10月）で多かった断り文句16種と、キャンセル・不在の防ぎ方を、同じ型でまとめた早見表です。

- 型：**① 受け止める → ② 聞く → ③ 事実（お客様の数字・資料）で返す → ④ 小さな次の一歩**、と **言わないこと**
- `objections.html` をひらき、お客様の言葉（転勤・親・怖い・NISA・忙しい…）で検索。段階（アポ／キャンセル／商談）で絞り込み。印刷可
- 商談報告を分析すると、そのお客様の断り文句と切り返しが「8.」に出る（`detect()`）
- 集計の詳しい結果：`経営管理/03_営業/客層と断り文句の切り返し_202610.md`

## 出てくるもの（8つ）

1. **数字の目安**：年収（直近・低い年）、希望の毎月の返済＋ボーナス払いで借りられる額（金利1.0%/1.5%）、返済比率（直近・低い年）、家賃からの増え方、完済の年齢。前提は画面に表示
2. **強み**：教員・公務員などの安定収入、若さ、年収の伸び、結婚（若者夫婦世帯の控除上乗せの可能性）、共働き、ボーナス
3. **将来のリスク（高・中・低）**：根拠になったヒアリングの行／将来どうなるか／**不動産の価値の伝え方**／確認すること／次にやること
4. **このお客様への伝え方（話の柱）**
5. **次回の確認事項**（チェックリスト）
6. **次にやること**（優先順。次の連絡日も拾う）
7. **書類**：段階（S0-S1／S2-S3／S5以降）ごとのそろい具合と未回収。今の段階の不足だけをリスクにする
8. **このお客様の断り文句と切り返し**（報告の文章から検出）

## 判定しているリスク（`lib/analyze.js` の `RISKS`）

| リスク | 手がかり | 重さ |
|---|---|---|
| 異動・転勤 | 異動・移動・転勤・6年ルール | 高 |
| 決める人（パートナー・家族）の不安 | 彼女・婚約者・妻・家族 ＋ 厳しい・反対・不安（2行に分かれていても可） | 高 |
| 確定申告の赤字 | 赤字 | 高 |
| 投資用不動産のローン | 投資不動産・投資用 | 高 |
| 貯金が少ない | 貯金・手付金 100万円未満＝高／300万円未満＝中 | 高・中 |
| 車のローン | 車(残○万)・おまとめ | 中 |
| 年収の上下 | 年収の最大と最小の差が15%超 | 中 |
| 外貨建て保険など | ドル建・外貨・変額 | 中 |
| 家族への援助 | 妹・親・仕送り ＋ 支払い | 中 |
| 家賃より支払いが増える | 希望の持ち出し − 今の家賃 ≥ 2万円 | 中 |
| ボーナス払い | 希望条件のボーナス払い | 中 |
| 書類不足 | 今の段階の書類が半分未満 | 中 |
| 商談の長期化 | ランクD以下・交渉4回以上 | 低 |

ルールを足す・直すときは `RISKS` / `STRENGTHS` に1件足すだけ（画面と CLI は表示だけ）。社内の営業マニュアルに合わせ、家族の反対には「決める人を同席させる」、転勤には「選択肢が残る立地」、ランクDは「深追いしない」を次のアクションにしています。

## 守っていること

- **お客様の情報はどこにも送らない・保存しない**（`fetch`・`localStorage` なし）。レポートにはお客様の氏名を出さない。分析結果はリポジトリにコミットしない（`.gitignore`）。
- **伝え方に禁止表現を入れない**：必ず値上がり／家賃は無駄／返済はすべて資産／必ず売れる／今だけ 等（`FORBIDDEN`、テストで確認）。
- 数字は概算。審査・税額・控除は金融機関・税務署の判断で変わる。〔要確認〕の項目は確認してから伝える。

設計の考え方は [`docs/設計.md`](docs/設計.md)。
