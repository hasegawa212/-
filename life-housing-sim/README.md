# 住まいの一生シミュレーター（life-housing-sim）

**賃貸のまま** と **持ち家** を、今から95歳まで同じ物差しで比べ、**どのお客様にも ①〜⑥ の同じ順番で説明できる** ツールです。不動産を勧めるためだけでなく、「持たない場合、将来どうなるか・何を準備すればいいか」までお客様が自分で分かることをねらいにしています。

```text
index.html をダブルクリック（または dist/住まいの一生シミュレーター.html を送って開いてもらう：1ファイルで動く）
左の ▼ を選ぶ → 右で ①〜⑥ を順番に「次へ」→ 最後に「印刷・PDF」でお渡し
```

## Zoom・画面共有で使う

| 操作 | やり方 |
|---|---|
| 画面共有モード | 「画面共有モード（Zoom）」ボタン、または `P` キー。左の入力を隠し、文字を大きくして 1280×720 の1画面に収める |
| ページ送り | 下のバーの「次へ／前へ」、または `→` `←`（`Space`・`PageDown` でも可）。プレゼン用のリモコンも使える |
| 全画面 | 下のバーの「全画面」、または `F` キー |
| 条件を変える | 下のバーの「条件を変える」、または `Esc` |
| 共有リンク | 「共有リンクをコピー」→ チャットやメールでお客様に送る。開くと同じ条件・画面共有モードで ① から見られる |

- 公開URL（main にマージ後）：**https://hasegawa212.github.io/-/life-housing-sim/** （Netlify の `/life-housing-sim/` でも同じ）
- 共有リンクは条件の数字だけを URL の `#` 以降に入れる（`#` 以降はサーバーに送られない）。**お名前は入らない**。知らない項目・ありえない数字は開くときに無視する（`lib/share.js`、テストあり）。
- 1ファイル版（`dist/住まいの一生シミュレーター.html`）も同じ機能。ファイルで開いた場合も共有リンクは作れるが、相手も同じファイルが必要なので、お客様に送るときは公開URLのリンクを使う。

## お客様への提案書（A4・4ページ・PDF）

「提案書（A4・PDF）」ボタンで、今の条件から **お客様にお渡しする提案書** を作ります → 「印刷・PDFで保存」。

| ページ | 中身 |
|---|---|
| 1. あなたのお金の全体像 | 表紙（お客様名・作成日・会社名・担当者）、年収と平均、生涯収入、そのうち住まいに使うお金、今と65歳の資産 |
| 2. 一生でかかる住まいのお金 | 一生の住居費（賃貸／持ち家）、内訳（元金・利息・税金・保険・修繕・住宅ローン控除）、累計グラフ |
| 3. 65歳からの暮らし | 年金と毎月の支出・不足、持たない場合の準備、もしも（独身／家族で文章が変わる）、待った場合の表 |
| 4. まとめと次の一歩 | 持つ・持たない・待つ それぞれの準備、**次の一歩のチェックリスト**（事前審査／ねんきんネット／条件の書き出し／賃貸のまま積立／見送り）、ご注意、連絡先 |

- お客様名・会社名・担当者・電話は左の「提案書」欄で入力（共有リンクや保存には入りません）
- 中身は `lib/engine.js` の `proposal(x, meta)`（テストあり）。画面は表示だけ

## 独身向けが初期値

商談のお客様の大半は独身（結婚願望「無し・あまり無し」71%）なので、**初期値は「独身・賃貸（家賃は平均）」**です。左上の「お客様のタイプ」で3つを切り替えられます（`preset("single" | "shataku" | "family")`）。

| タイプ | 家賃 |
|---|---|
| 独身・賃貸（家賃は平均） | ひとり暮らし 5.8万円＝当社のお客様の家賃の中央値（`RENT_AVG`） |
| 独身・社宅（30歳ごろまで） | 30歳までは自己負担 2万円（更新料なし）→ 社宅を出たら 5.8万円。買う年齢の初期値は社宅を出る30歳 |
| 結婚・子どもあり | 30歳で結婚・32歳で第1子。家賃は ひとり→2人→子育て→老後 |

社宅の自己負担・出る年齢は「社宅（会社の寮・借り上げ社宅）」の欄で変えられます（会社の規定に合わせる）。社宅の人には①で「社宅を出ると毎月いくら・年いくら家賃が上がるか」を数字で見せます。

独身のときは説明も変わります：
- ① ひとりで暮らしていく場合も家賃は一生続く。持ち家なら、結婚しても住み続ける・貸す・売るを選べる
- ③ ひとり分の年金から家賃を払い続ける
- ⑤ いちばんの心配は「年を取ってからの住まい」（高齢のひとり暮らしは入居を断られることがある）。団信で万一のときもローンが親や兄弟に残らない（「家族に住まいが残る」という家族向けの話はしない）
- 住宅ローン控除は一般の限度額（上乗せなし）

※独身・家賃が安めの場合、⑥の「差額を運用した場合」が持ち家の価値を上回ることもあります。その結果もそのまま見せます（公平な比較）。

## 説明の8ステップ（全員同じ）

| ステップ | 見せるもの | お客様に聞くこと |
|---|---|---|
| ⓪ あなたのお金の全体像 | **ポートフォリオ**（今と65歳の 預貯金・NISA・不動産、保険）、**年収 vs 一般の平均給与 459.5万円**、**生涯収入（給料＋年金）と、そのうち住まいに使う割合** | 今の預金・NISA・保険・不動産のバランスに満足しているか |
| ① これからの暮らしの段階 | ひとり→2人→子育て→老後 の家賃の変化 | 結婚・子ども・働き方の予定 |
| ② 一生でかかる住まいのお金 | 今〜95歳の住居費の累計グラフ＋**一生で払うお金の内訳**（家賃・更新料／保険／税金／頭金・諸費用／元金／利息／修繕／**住宅ローン控除で戻る税金**） | 税金や保険まで含めて考えたことはあるか |
| ③ 65歳からの30年 | 年金（概算）と、老後の毎月の支出（賃貸／持ち家） | 老後どこに、どんな家に住みたいか |
| ④ 持たないなら、いくら準備が必要か | 65歳までに準備したいお金と毎月の積立額（賃貸／持ち家） | その積立を続けられそうか |
| ⑤ もしものとき | 団信（残りのローン0・家族に住まいが残る）、金利が1%上がったら、高齢期の賃貸、**生命保険**（団信で見直せる分） | 家族にどう住まいを残したいか |
| ⑥ まとめ | 65歳時点の家の価値（3シナリオ）と、差額を運用した場合（公平な比較） | どちらの準備が自分に合うか |
| ⑦「今はいい」と思ったら | 1・3・5年待つと：**待つ間の家賃・完済年齢・65歳を過ぎて返す年数・毎月の返済**、仮に金利が0.5%上がった場合。待つ理由の整理（転勤・結婚・貯金／なんとなく） | 待つ理由は何か、その理由がなくなるのはいつか |

⑦は「今はいい」というお客様に、**脅しや断定ではなく、ご本人の数字で待つコストを見せる**ためのページです（宅建業法の断定的判断の提供・威迫にあたる言い方はしない）。待つ理由がはっきりしていれば待つのも選択肢、理由がなければ「待つ間の家賃と遅れる完済」を知ったうえで決めてもらいます。

各ステップに「話すこと（say）・見せる数字（show）・聞くこと（ask）」があり、営業が変わっても同じ説明になります（`lib/engine.js` の `talk()`）。

## 入力（すべて ▼ から選ぶ）
年齢・年収・貯金／結婚する年齢・子ども・パートナーの年収／暮らしの段階ごとの家賃（地域の目安）・家財保険／買う年齢・物件価格・金利・返済年数・**住宅の種類（住宅ローン控除）・固定資産税・火災地震保険**／**生命保険と団信で見直せる分**／老後の生活費。初期値は #03_商談報告 の中央値に近いお客様像（27歳・年収390万・貯金140万）。

## 計算の前提（画面の下にも表示）
- 年金：基礎年金を満額（令和8年度 847,300円）＋厚生年金「年収÷12（上限65万）× 5.481/1000 × 加入月数」の概算。ねんきんネットで確かめる。
- 賃貸：家賃×12＋更新料（2年ごとに1か月）。持ち家：返済＋固定資産税・保険・修繕（20年目から1.5倍）。諸費用はローンに含める設定。
- 家の価値：土地 年−1%／0%／＋1%、建物は30年で1割まで。**将来の価格は約束しない。**
- 税金：固定資産税・都市計画税（毎年・入力）。取得時の税金（不動産取得税・登録免許税・印紙税）は諸費用（物件価格の7%と仮定）に含む。
- 住宅ローン控除（2026〜2027年入居の制度）：住宅の種類ごとの限度額・期間（中古・買取再販その他 2,000万円・10年、ZEH 3,500万円・13年 など）。結婚後（40歳未満）や子育て中の入居で限度額が上がる住宅は上乗せ。年末残高×0.7% を、**給与から概算した所得税→住民税（課税所得×5%・最高97,500円）の範囲で**戻す（控除しきれない額は数えない）。「制度上の上限」と「戻る見込み」を分けて表示。
- 保険：賃貸は家財保険、持ち家は火災・地震保険（毎年）。生命保険は住まいとは別に表示し、団信で見直す分を設定したときだけ持ち家側を減らす。
- 公平な比較：賃貸の人が持ち家との差額を積み立てて年3%で運用できた場合も出す（元本保証なし）。

## 守っていること
- 「家賃は無駄」「必ず値上がり」「今買わないと損」などの言い方はしない（`FORBIDDEN`、テストで確認）。「どちらが正解ということはない」「持たないなら準備が必要」と伝える。
- 通信なし・保存なし（お客様の情報は画面を閉じると消える）。
