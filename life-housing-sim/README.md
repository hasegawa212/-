# LIFE ROUTE（ライフルート）— 住まいとお金、95歳までの道のり（life-housing-sim）

旧名：住まいの一生シミュレーター。公開URL（`/life-housing-sim/`）は、送ったリンクが切れないようにそのまま。

**賃貸のまま** と **持ち家** を、今から95歳まで同じ物差しで比べ、**どのお客様にも ①〜⑥ の同じ順番で説明できる** ツールです。不動産を勧めるためだけでなく、「持たない場合、将来どうなるか・何を準備すればいいか」までお客様が自分で分かることをねらいにしています。

```text
index.html をダブルクリック（または dist/ライフルート.html を送って開いてもらう：1ファイルで動く）
左の ▼ を選ぶ → 右で ①〜⑥ を順番に「次へ」→ 最後に「印刷・PDF」でお渡し
```

## お客様に見せる資料（16:9・16枚／独身のお客様は17枚）「賃貸より、購入。」
「お客様に見せる資料（16:9）」ボタンで、購入をおすすめする資料になります：表紙「家賃を払い続けるより、自分の家を。」→（独身のお客様だけ）「買うのは、家だけじゃない。自分の空間だ」の絵＋今の家賃と毎月の返済 → 固定費 → 結論（購入をおすすめします）→ 理由1〜6（一生の住居費・老後の毎月・65歳の資産・老後への準備・団信・住宅ローン控除）→ 待つと → 親御さまの頃との違い → 購入する前に確認しておくこと → 進め方 → 審査の前に、自分の信用を知る → 次の一歩。理由はすべてお客様の数字で、数字が購入に向かないお客様には「おすすめ」と出しません。注意点のスライドは必ず入ります。営業マンが話すこと・質問は各スライドの下のノート（印刷には入りません）。「1枚ずつ見せる」で Zoom・タブレット、「印刷・PDFで保存」で16:9のPDF。見本：`dist/ライフルート_お客様資料_見本.pdf`（`npm run build && npm run deck`）。

## ⑦ 賃貸と購入、どちらがいいか（購入をすすめる）
⑦まとめは、お客様の数字（一生の住居費の実質・老後の毎月の不足・65歳までの準備・65歳の資産）で比べて、持ち家が有利なら「購入をおすすめします」（審査の目安に△があれば「見直して事前審査で確かめてから」）と出します。数字が合わないお客様には無理にすすめず「今は準備」。金利・修繕と税金・値下がり・差額の運用などの注意点も必ず一緒に見せます（`recommend(x)`）。

## ¥ 節約するなら、いちばん大きな固定費から（説明のいちばん最初）
「節約しなさい」と言われて育った方に、何を節約すると一番効くか → 毎月いちばん大きな固定費＝住まい（家賃）を見せます。賃貸の仕組みの絵（押すと大きく表示）と、お客様の家賃・手取りに占める割合・65歳／95歳まで払い続けた合計（`fixedCost(x)`）。家賃は住まいの対価で、オーナーのローンの返済や将来の備えにもつながっている、と否定せずに伝えます。前に送った共有リンクも同じステップが開きます。

## ⑧ 親御さまに反対されたら（バブル崩壊のイメージ）
「親に相談したら反対された」というお客様には、⑧で親御さまの頃（1990年前後）との違いを数字で見せます（`bubble(x)`）。同じ借入額・年数でも、当時の金利 8.5%（公庫 約5.5%）なら毎月いくらか、今の計画ならいくらか。親御さまの心配は否定せず、「値上がりをあてにせず、住むために払える範囲で考える」「値下がりもありうる（⑦の下落シナリオ）」をセットで伝えます。商談での切り返しは `hearing-risk-analyzer` の「親に相談したら反対された」を参照。

## ⑤ 団信と生命保険のくらべ
⑤ もしものとき に、団体信用生命保険（団信）と生命保険を並べました（`danshin(x)`）。

| | 団信 | 生命保険 |
|---|---|---|
| 何を守るか | 住宅ローンの残り（万一のとき残りがなくなる） | 家族の生活費など（契約した保障額） |
| 保障額 | 借りた額 → 返すほど減り完済で0 | 一定（入力「生命保険の保障額」、初期値1,000万円） |
| 保険料 | 一般団信は金利に含まれ別払いなし（多くの金融機関） | 毎月の保険料 |
| 生命保険料控除 | 対象外 | あり |

- 保障額の動きのグラフ（団信＝ローンの残りの線、生命保険＝一定の点線）
- がん団信・3大疾病付き・ワイド団信は金利上乗せの目安（+0.1／+0.2／+0.3%）で、毎月・総額いくら増えるかを表示（`DANSHIN_OPTIONS`。金融機関・商品で違うので確認）
- 返している間に生命保険を減らす額（入力「団信で減らせる分」）を入れると、見直し額を表示
- 提案書3ページ目にも1行で入る

## ⑥ 区切り：まず「できるか」→ その土台で「やるか」
説明は ⓪〜⑧ の9ステップ。⑤もしも の次に **⑥ まず「できるか」を確かめる（区切り）** を入れ、⑦まとめ（やる・やらない）、⑧「今はいい」と続きます。

- 住宅ローンは、借りたい人や私たちではなく **融資する金融機関が決める**。当社で審査を申し込んだ方のうち、通るのは **10人中2〜3人ほど（目安）**（`PASS_RATE`。年・地域・金融機関で変わる）
- だから、やるか・やらないかを決める前に、まず「できるか」をこちらで確認する → その土台に乗ったら、通った金額の範囲で決めてもらう（できるかわからないまま決めても意味がなく、お客様の時間を無駄にしないための順番）
- 画面：10人の人型（2〜3人が金色）、①できるか（事前審査・無料・購入の義務なし）→ ②やるか・やらないか、数字で見る目安（返済比率・年収の何倍・完済年齢・定年後の返済、○／△見直し）と判定、金融機関が見ること（勤続・他の借入・信用情報・団信・担保評価）。通らなかったときの道（整えて時期を改める／賃貸のまま準備）も示す
- 提案書4ページ目の先頭とトップのおすすめアクションにも入る（`gate(x)`）
- **⓪ CIC取得**：事前審査の前に、お客様自身が CIC で信用情報を取り寄せる（本人開示：インターネット 500円・その場でPDF／郵送 1,500円・約10日。窓口は終了。`CIC` に1か所で定義し、手数料・方法は変わることがあるので公式 https://www.cic.co.jp/mydata/ で確認）。返済の遅れ・他の借入・最近の申し込みを先に自分で確かめる。⑥の画面（⓪→①→②）・提案書の次の一歩の先頭・トップのミッションに入る

## 2人暮らしの家賃「なし」
「2人暮らし」の欄で「なし（ひとり暮らしと同じ）」を選べます。結婚後（子育て期の前）も、ひとり暮らしの家賃のまま計算します（団信のときに家族が払い続ける家賃も同じ）。

## 定年・再雇用とローンの回数
- 初期値は **60歳で定年 → 65歳まで再雇用（年収は定年前の6割と仮定）→ 65歳から年金**。「あなたのこと」の欄で定年の年齢・再雇用の割合を変えられます。
- 生涯の給料・厚生年金は、再雇用の5年を下がった年収で計算します。
- ローンは **月で数えます（35年＝420回払い）**。③と提案書に「60歳の時点で360回払って残り60回（残高）」「再雇用の間の返済は年収の何%」「何歳で完済」を出します。35%を超えるときは、繰上げ返済・退職金で残りを減らす計画も一緒に考える、と添えます。

## トップページ（LIFE ROUTE）（お客様が主人公）
開くと最初に出る画面です（共有リンクで ステップ・画面共有 の指定があるときはそのステップから）。

- 主人公＝お客様：右上でお名前を入れると「◯◯ 様」。地図の道の上に後ろ姿と名前の旗。会社名は「提案書」欄の会社名（初期値は合同会社ジャパンマネジメント、`DEFAULT_COMPANY`）
- 地図の5つのエリア（現預金・NISA・保険・不動産・ライフプラン）に、その人の数字と「Lv.」。押すと説明のステップへ
- Lv.＝1＋できたミッションの数。ミッションは自動判定（NISAの積立・家賃6か月分の貯金・このシミュレーション）とチェック（事前審査〈無料・購入の義務なし〉・物件を見る・保険の見直し・ねんきんネット）
- 右側：今の資産（不動産／NISA／預貯金の割合）と65歳までの見通し、人生の目標（65歳までに準備したいお金に対して今いくら）、ライフイベント（今・社宅を出る・結婚・子ども・家を買う・定年・年金・完済）
- おすすめのアクション4つ、「次のステージへ」で ⓪ から説明開始。左のメニューから各ステップ・提案書・画面共有・条件の変更へ
- **映像と数字の連動**：地図の金色の道に、ライフイベントの印（27歳 今 → 30歳 家を買う → 60歳 定年 → 65歳 年金・完済）。印・右のグラフの点・ライフイベントの行のどれを押しても（指を乗せても）同じ年齢が一緒に光り、地図の左下に その年の数字（例：60歳 年収234万円・ローン残り60回・残高509万円、その年の資産）が出る。エリアのカードは大きな数字1つ＋何の数字か（`home().milestones`・`areas[].big`）。スマホでは道の印を省き、同じ数字を一覧と詳しい欄で見せる
- 数字はすべて `home(x, done, meta)`（`lib/engine.js`）から。見本の数字や根拠のない上昇率は出さない（テストで確認）。お名前とチェックは画面の中だけ（保存・共有しない）

## 賃貸の更新料と、審査が通りにくくなること
- **更新料**：2年ごとに家賃1か月分（欄で 0〜2か月・1〜3年ごとに変更可、社宅の間は0）。②の表に「更新料（2年ごとに1か月分・34回）197万円」と別の行で出し、提案書にも入れる（`x.renew`）。
- **老後の賃貸の入居審査**：65歳からは収入が年金だけ。家賃÷年金を出し、一般的な目安（収入の3分の1以内）を超えると「通りにくくなる場合があります」（⑤のカード・提案書③、`x.screening.rent`）。
- **住宅ローンの審査**：⑦の表に、待った場合の返済比率（毎月の返済×12÷その年の年収、目安 年収400万円未満30%・以上35%）を出し、年齢が上がると期間が短くなる・団信に入れない場合があることを添える（`wait[].screen`）。
- どれも「目安」「場合があります」で、断定しない（実際の審査は金融機関・管理会社ごとに違う）。

## 独身向けが初期値

商談のお客様の大半は独身（結婚願望「無し・あまり無し」71%）なので、**初期値は「独身・賃貸（家賃は平均）」**です。左上の「お客様のタイプ」で3つを切り替えられます（`preset("single" | "shataku" | "family")`）。

| タイプ | 家賃 |
|---|---|
| 独身・賃貸（家賃は平均） | ひとり暮らし 5.8万円＝当社のお客様の家賃の中央値（`RENT_AVG`） |
| 独身・社宅（30歳ごろまで） | 30歳までは自己負担 2万円（更新料なし）→ 社宅を出たら 5.8万円。買う年齢の初期値は社宅を出る30歳 |
| 結婚・子どもあり | 30歳で結婚・32歳で第1子。家賃は ひとり→2人→子育て→老後 |

社宅の自己負担・出る年齢は「社宅（会社の寮・借り上げ社宅）」の欄で変えられます（会社の規定に合わせる）。社宅の人には①で「社宅を出ると毎月いくら・年いくら家賃が上がるか」を数字で見せます。

独身のときは説明も変わります：
- ① ひとりで暮らしていく場合も家賃は一生続く。持ち家なら、結婚しても住み続ける・貸す・売るを選べる
- ③ ひとり分の年金から家賃を払い続ける
- ⑤ いちばんの心配は「年を取ってからの住まい」（高齢のひとり暮らしは入居を断られることがある）。団信で万一のときもローンが親や兄弟に残らない（「家族に住まいが残る」という家族向けの話はしない）
- 住宅ローン控除は一般の限度額（上乗せなし）

※独身・家賃が安めの場合、⑥の「差額を運用した場合」が持ち家の価値を上回ることもあります。その結果もそのまま見せます（公平な比較）。

## 説明の8ステップ（全員同じ）

| ステップ | 見せるもの | お客様に聞くこと |
|---|---|---|
| ⓪ あなたのお金の全体像 | **ポートフォリオ**（今と65歳の 預貯金・NISA・不動産、保険）、**年収 vs 一般の平均給与 459.5万円**、**生涯収入（給料＋年金）と、そのうち住まいに使う割合** | 今の預金・NISA・保険・不動産のバランスに満足しているか |
| ① これからの暮らしの段階 | ひとり→2人→子育て→老後 の家賃の変化 | 結婚・子ども・働き方の予定 |
| ② 一生でかかる住まいのお金 | 今〜95歳の住居費の累計グラフ＋**一生で払うお金の内訳**（家賃・更新料／保険／税金／頭金・諸費用／元金／利息／修繕／**住宅ローン控除で戻る税金**） | 税金や保険まで含めて考えたことはあるか |
| ③ 65歳からの30年 | 年金（概算）と、老後の毎月の支出（賃貸／持ち家） | 老後どこに、どんな家に住みたいか |
| ④ 持たないなら、いくら準備が必要か | 65歳までに準備したいお金と毎月の積立額（賃貸／持ち家） | その積立を続けられそうか |
| ⑤ もしものとき | 団信（残りのローン0・家族に住まいが残る）、金利が1%上がったら、高齢期の賃貸、**生命保険**（団信で見直せる分） | 家族にどう住まいを残したいか |
| ⑥ まとめ | 65歳時点の家の価値（3シナリオ）と、差額を運用した場合（公平な比較） | どちらの準備が自分に合うか |
| ⑦「今はいい」と思ったら | 1・3・5年待つと：**待つ間の家賃・完済年齢・65歳を過ぎて返す年数・毎月の返済**、仮に金利が0.5%上がった場合。待つ理由の整理（転勤・結婚・貯金／なんとなく） | 待つ理由は何か、その理由がなくなるのはいつか |

⑦は「今はいい」というお客様に、**脅しや断定ではなく、ご本人の数字で待つコストを見せる**ためのページです（宅建業法の断定的判断の提供・威迫にあたる言い方はしない）。待つ理由がはっきりしていれば待つのも選択肢、理由がなければ「待つ間の家賃と遅れる完済」を知ったうえで決めてもらいます。

各ステップに「話すこと（say）・見せる数字（show）・聞くこと（ask）」があり、営業が変わっても同じ説明になります（`lib/engine.js` の `talk()`）。

## 入力（すべて ▼ から選ぶ）
年齢・年収・貯金／結婚する年齢・子ども・パートナーの年収／暮らしの段階ごとの家賃（地域の目安）・家財保険／買う年齢・物件価格・金利・返済年数・**住宅の種類（住宅ローン控除）・固定資産税・火災地震保険**／**生命保険と団信で見直せる分**／老後の生活費。**お客様ごとの項目（年齢・年収・貯金・NISA残高／毎月・家賃（社宅なら自己負担と出る年齢）・物件価格・生命保険 毎月／保障額）は空（「選んでください」）から始まり、全部選ぶまで数字は出ません**（見本の数字をお客様に見せないため。共有リンクで開いたときはリンクの条件を使います）。金利・老後の生活費などの仮定は、#03_商談報告 の中央値に近いお客様像を初期値にしています。

## 計算の前提（画面の下にも表示）
- 年金：基礎年金を満額（令和8年度 847,300円）＋厚生年金「年収÷12（上限65万）× 5.481/1000 × 加入月数」の概算。ねんきんネットで確かめる。
- 賃貸：家賃×12＋更新料（2年ごとに1か月）。持ち家：返済＋固定資産税・保険・修繕（20年目から1.5倍）。諸費用はローンに含める設定。
- 家の価値：土地 年−1%／0%／＋1%、建物は30年で1割まで。**将来の価格は約束しない。**
- 税金：固定資産税・都市計画税（毎年・入力）。取得時の税金（不動産取得税・登録免許税・印紙税）は諸費用（物件価格の7%と仮定）に含む。
- 住宅ローン控除（2026〜2027年入居の制度）：住宅の種類ごとの限度額・期間（中古・買取再販その他 2,000万円・10年、ZEH 3,500万円・13年 など）。結婚後（40歳未満）や子育て中の入居で限度額が上がる住宅は上乗せ。年末残高×0.7% を、**給与から概算した所得税→住民税（課税所得×5%・最高97,500円）の範囲で**戻す（控除しきれない額は数えない）。「制度上の上限」と「戻る見込み」を分けて表示。
- **そろえる書類**（`SCREEN_DOCS`）：信用情報（CIC）／本人確認書類（運転免許証・健康保険証・マイナンバーカードのどれか）／源泉徴収票 2期分（直近2年分）
- **審査のあとの流れ**（`FLOW`）：事前審査 → 内見 → 売買契約 → 本申込（本審査）→ 金銭消費貸借契約 → 決済・引き渡し（⑥の画面・提案書の次の一歩）

## ② 「持ち家のほうが高い？」に答える（消えるお金でくらべる）
持ち家の一生の合計には **家そのものの代金（返した元金＋頭金）** が入っていて、払い終わった家は自分のものとして残ります。そこで②では合計どうしではなく「**消えるお金**」どうしをくらべます（`costCompare(x)`）：賃貸＝家賃・更新料・家財保険の全部／持ち家＝利息・税金・保険・修繕・買うまでの家賃 −控除。あわせて「家の代金（残る分）」と **毎月の住居費**（今の家賃 vs 返済＋税金・保険・修繕）も出します。合計の内訳は表の最後の行に残しています。

## 今の経済の数字（物価・預金金利・老後2000万円問題・貯蓄型保険）
`ECONOMY`（2026年10月時点・出典つき）と `economy(x)`。
- ③：**老後2000万円問題**（金融審議会 報告書・2019年＝当時の平均的な無職の夫婦の毎月約5.5万円の不足×30年）と、**あなたの場合**の不足（賃貸のまま／持ち家）をならべる
- ④：**物価と預金**。全国の消費者物価（生鮮食品を除く）2026年9月 +2.1%（総務省）、メガバンクの普通預金 年0.5%（2026年11月2日から）。**仮に**このまま続くと、65歳の生活費がいくら相当になるか・預金の買える量がどれだけ目減りするか（試算そのものは物価一定）
- ⑤：**貯蓄型保険**は早く解約すると払った額より戻りが少ない場合がある。保障と貯蓄は分けて考える
- 数字は変わるので、使う前に出典（総務省統計局・各銀行の発表・金融庁）で確かめ、`ECONOMY` を1か所直す。テスト：`test/economy.test.js`

## 社宅を出る年齢「なし」
「社宅を出る年齢（規定）」に **なし（決まりなし・定年まで）** を選べます（値は0）。社宅に住めるのは在職中だけなので、定年（初期値65歳）までを社宅の自己負担で計算し、そのあとはふつうの家賃にします。説明①は「社宅を出る年齢の決まりはありません。ただ、社宅に住めるのは会社にお勤めの間だけで、定年までです」、条件の表示は「定年の65歳まで・出る年齢の決まりなし」になります。

## 会社員の信用 →「買うか、買わないか。決めるのはあなた。」（⑥）
`trust(x)`：会社員として勤めて安定した給与を受け取っている実績は、住宅ローンの審査で**評価されることがある**（断定しない）。⑥に「会社員として積み上げた信用を、将来の選択肢に。／住宅ローンの事前審査は、家を買う約束ではない。／**買うか、買わないか。決めるのはあなた。**」と、会社員と個人事業主の比較（収入の証明・評価・必要書類・審査のポイント）を出し、注意書き「事前審査の承認は本審査の承認や融資実行を保証せず、有効期限や物件条件などの制約があります」を必ず添えます。営業トーク（信用 → 使えるかは審査してみないとわからない → 事前審査はチケット → 使うか使わないかはお客様が決める）は資料「進め方」のノート（続けて）に入ります。入力「働き方」を個人事業主にすると、「会社員の信用」とは言わず、確定申告書（直近2〜3期分・金融機関で異なる）と所得の推移の話にかわり、そろえる書類も確定申告書になります。Zoomでは1画面に収めるため、メッセージは下の問いかけ（決めるのはあなたです）で伝えます。

`screenPrep(x)`（審査の前に、自分の信用を知る）：いただいた事前審査の画像の中身を、画面の文字で正直に作り直したものです（画像は銀行のロゴと「通りやすい」「購入できる状態をクリア」の言い切りがあるため使いません）。「10人中2〜3人」は**当社の目安**と書き、記録がなくても審査の基準で通らないことがある6つ（カード・スマホ本体の分割払いの遅れは記録に残ることがある／カード・ローンの数や利用枠・勤続年数・転勤の予定・物件の評価）、CICに記録される情報5つ、購入までの5ステップ（CIC → 適性チェック → 事前審査（本人の同意のうえ）→ 結果（本審査・融資を保証しない・有効期限あり・買う義務なし）→ 使うか、今は持っておくかは自分で決める）、事前審査で広がる選択肢4つ（価値は上がることも下がることも・税金と修繕はかかる）を出します。銀行名は出しません。⑥の下（Zoomでは非表示）と、資料の「進め方」の次の1枚に入ります。テスト：`test/prep.test.js`。

`fitCheck(x, 答え)`（住宅ローンの適性チェック）：⑥でお客様と一緒に11の質問（支払いの遅れ・スマホ本体の分割払い・カードの枚数・リボ／キャッシング・ほかの借入・勤続・働き方・半年以内の申し込み・転勤の予定・自分で住むか・団信）にボタンで答えると、「事前審査の前に確かめること」が出ます。合否は出さず、いつも「決めるのは金融機関」と書きます。入力済みの条件（個人事業主・転勤あり・ほかの借入あり）は答えを先に入れておき、変えられます。もう一度押すと答えを消せます。**答えはページの中だけで、保存も共有リンクへの記録もしません**（支払いの遅れなどは大事な個人の情報のため）。Zoomでは表示しません。テスト：`test/fitcheck.test.js`。

## 現場が必要としている知識（販売に必要な知識マトリクス・出現頻度順）
ツール列の **「営業の知識（社内用）」** で、Tier 1〜4（必須・標準・応用・専門）の18項目を、ひとこと答え＋LIFE ROUTEのどこで見せるか＋このお客様の数字つきで見られます（`KNOWLEDGE`。お客様には見せない画面・件数など社内の数字は出さない）。特に足りなかった5つを画面と台本に入れました：
- **転勤リスクを数字で**（入力「転勤の可能性」「貸した場合の家賃」）：⑤に「転勤になったら」＝単身赴任（控除はそのまま）／転勤の間だけ貸す（家賃−管理費5%−空室1か月/年 と 返済＋維持費をくらべた毎月の持ち出し・手元、**金融機関の承諾が必要**）／売る（10年後の手元の目安）。控除は家族全員で転居すると止まり期間は延びない・戻るなら事前に「転任の命令等により居住しないこととなる旨の届出書」。物件選びの3つの軸・まず聞く4つ・言ってはいけないこと（転勤族向けスクリプトより）。転勤ありのお客様だけ資料に「転勤になっても、選べる道は3つ」の1枚（`transfer(x)`）
- **ご家族（親）への説明**：⑧に「ご家族と一緒に」＝早めに同席・同じ資料を渡す・当時と今の金利・下落シナリオ・決めるのはご本人とご家族（`familyTalk(x)`）
- **NISAとの違い**：④に表（どちらも元本保証なし・役割・税・換金しやすさ・両方使える）（`nisaCompare(x)`）
- **借入不安を段階的に**（入力「他の借入」）：⑥に「他の借入を含む返済比率」と、借入を整理 → CIC → 事前審査 → 本審査（`debtPlan(x)`）
- **金利上昇**：⑤に +0.5/+1/+2% の毎月と総額、変動と固定のちがい（5年ルール・125%ルールは金融機関で異なる）（`rateRisk(x)`）

Zoomの画面共有では、これらの表は省きます（話す内容は台本にあります）。

## 「毎月の家賃、そのまま払い続けますか？」（② と 資料の結論の次）
`future(x)`：左に賃貸、右に戸建て購入。毎月（今の家賃 vs 返済＋税金・保険・修繕）→ 10年後・20年後（払った家賃／払った返済・返した元金・ローン残高・家の価値の目安（横ばい）−残高−売却費用（仲介手数料の上限）＝売った場合の手元。マイナスもそのまま）→ 老後（完済後の住居費 vs 老後の家賃、住み替え・売却・賃貸の選択肢）。締めの一文は「家賃は、住むための支払い。住宅ローンは、住みながら自分の家を持つための支払い。」。数字はすべてお客様の条件の概算で、頭金・諸費用・税金・保険・修繕がかかること、家の価値は下がる場合もあることを必ず添えます。準備をすすめるお客様には問いかけの見出しにせず「くらべると」にします。Zoomの画面共有では②のこの表は省きます。

## 「今払ってる賃料が将来の資産になる」の絵（② と 資料の結論）
`img/rent-to-asset.jpg`（`assetImage(x)`）。②の「消えるお金」の下と、お客様に見せる資料の結論（購入をおすすめするときだけ。準備をすすめるときは今までの表）に出します。添える文は正直に：家賃そのものではなく、家賃のかわりに返した元金（頭金を含む）が家の代金として残る・家の価値は上がることも下がることもある。Zoomの画面共有では②の絵は省きます。

## 保存したお客様（担当ごと・消せる）
「保存したお客様」（ツール列・トップの左メニュー・条件バー・入力の確認画面）で、今の条件をお客様のお名前と担当者で保存し、担当ごとに一覧・開く・消す・全部消すができます（`lib/customers.js`）。**この端末のブラウザの中（localStorage `lhs_customers_v1`）だけに保存し、どこにも送りません。** お名前が入るので、共用の端末では使い終わったら消してください。共有リンクには今までどおりお名前は入りません。

- 保険：賃貸は家財保険、持ち家は火災・地震保険（毎年）。生命保険は住まいとは別に表示し、団信で見直す分を設定したときだけ持ち家側を減らす。
- 公平な比較：賃貸の人が持ち家との差額を積み立てて年3%で運用できた場合も出す（元本保証なし）。
