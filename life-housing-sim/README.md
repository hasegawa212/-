# 住まいの一生シミュレーター（life-housing-sim）

**賃貸のまま** と **持ち家** を、今から95歳まで同じ物差しで比べ、**どのお客様にも ①〜⑥ の同じ順番で説明できる** ツールです。不動産を勧めるためだけでなく、「持たない場合、将来どうなるか・何を準備すればいいか」までお客様が自分で分かることをねらいにしています。

```text
index.html をダブルクリック（または dist/住まいの一生シミュレーター.html を送って開いてもらう：1ファイルで動く）
左の ▼ を選ぶ → 右で ①〜⑥ を順番に「次へ」→ 最後に「印刷・PDF」でお渡し
```

## 説明の6ステップ（全員同じ）

| ステップ | 見せるもの | お客様に聞くこと |
|---|---|---|
| ① これからの暮らしの段階 | ひとり→2人→子育て→老後 の家賃の変化 | 結婚・子ども・働き方の予定 |
| ② 一生でかかる住まいのお金 | 今〜95歳の住居費の累計グラフ（賃貸／持ち家） | 一生の住まいのお金を計算したことはあるか |
| ③ 65歳からの30年 | 年金（概算）と、老後の毎月の支出（賃貸／持ち家） | 老後どこに、どんな家に住みたいか |
| ④ 持たないなら、いくら準備が必要か | 65歳までに準備したいお金と毎月の積立額（賃貸／持ち家） | その積立を続けられそうか |
| ⑤ もしものとき | 団信（残りのローン0・家族に住まいが残る）、金利が1%上がったら、高齢期の賃貸 | 家族にどう住まいを残したいか |
| ⑥ まとめ | 65歳時点の家の価値（3シナリオ）と、差額を運用した場合（公平な比較） | どちらの準備が自分に合うか |

各ステップに「話すこと（say）・見せる数字（show）・聞くこと（ask）」があり、営業が変わっても同じ説明になります（`lib/engine.js` の `talk()`）。

## 入力（すべて ▼ から選ぶ）
年齢・年収・貯金／結婚する年齢・子ども・パートナーの年収／暮らしの段階ごとの家賃（地域の目安）／買う年齢・物件価格・金利・返済年数／老後の生活費。初期値は #03_商談報告 の中央値に近いお客様像（27歳・年収390万・貯金140万）。

## 計算の前提（画面の下にも表示）
- 年金：基礎年金を満額（令和8年度 847,300円）＋厚生年金「年収÷12（上限65万）× 5.481/1000 × 加入月数」の概算。ねんきんネットで確かめる。
- 賃貸：家賃×12＋更新料（2年ごとに1か月）。持ち家：返済＋固定資産税・保険・修繕（20年目から1.5倍）。諸費用はローンに含める設定。
- 家の価値：土地 年−1%／0%／＋1%、建物は30年で1割まで。**将来の価格は約束しない。**
- 公平な比較：賃貸の人が持ち家との差額を積み立てて年3%で運用できた場合も出す（元本保証なし）。

## 守っていること
- 「家賃は無駄」「必ず値上がり」「今買わないと損」などの言い方はしない（`FORBIDDEN`、テストで確認）。「どちらが正解ということはない」「持たないなら準備が必要」と伝える。
- 通信なし・保存なし（お客様の情報は画面を閉じると消える）。
