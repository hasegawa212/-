# LIFE ROUTE（ライフルート）— 住まいとお金、95歳までの道のり（life-housing-sim）

旧名：住まいの一生シミュレーター。公開URL（`/life-housing-sim/`）は、送ったリンクが切れないようにそのまま。

**賃貸のまま** と **持ち家** を、今から95歳まで同じ物差しで比べ、**どのお客様にも ①〜⑥ の同じ順番で説明できる** ツールです。不動産を勧めるためだけでなく、「持たない場合、将来どうなるか・何を準備すればいいか」までお客様が自分で分かることをねらいにしています。

```text
index.html をダブルクリック（または dist/ライフルート.html を送って開いてもらう：1ファイルで動く）
左の ▼ を選ぶ → 右で ①〜⑥ を順番に「次へ」→ 最後に「印刷・PDF」でお渡し
```

## お客様への提案書（A4・4ページ・PDF）

| 2. 一生でかかる住まいのお金 | 一生の住居費（賃貸／持ち家）、内訳（元金・利息・税金・保険・修繕・住宅ローン控除）、累計グラフ |
| 3. 65歳からの暮らし | 年金と毎月の支出・不足、持たない場合の準備、もしも（独身／家族で文章が変わる）、待った場合の表 |
| 4. まとめと次の一歩 | 持つ・持たない・待つ それぞれの準備、**次の一歩のチェックリスト**（事前審査／ねんきんネット／条件の書き出し／賃貸のまま積立／見送り）、ご注意、連絡先 |

## ⑧ 親御さまに反対されたら（バブル崩壊のイメージ）
「親に相談したら反対された」というお客様には、⑧で親御さまの頃（1990年前後）との違いを数字で見せます（`bubble(x)`）。同じ借入額・年数でも、当時の金利 8.5%（公庫 約5.5%）なら毎月いくらか、今の計画ならいくらか。親御さまの心配は否定せず、「値上がりをあてにせず、住むために払える範囲で考える」「値下がりもありうる（⑦の下落シナリオ）」をセットで伝えます。商談での切り返しは `hearing-risk-analyzer` の「親に相談したら反対された」を参照。

## ⑤ 団信と生命保険のくらべ
⑤ もしものとき に、団体信用生命保険（団信）と生命保険を並べました（`danshin(x)`）。

| | 団信 | 生命保険 |
|---|---|---|
| 何を守るか | 住宅ローンの残り（万一のとき残りがなくなる） | 家族の生活費など（契約した保障額） |
| 保障額 | 借りた額 → 返すほど減り完済で0 | 一定（入力「生命保険の保障額」、初期値1,000万円） |
| 保険料 | 一般団信は金利に含まれ別払いなし（多くの金融機関） | 毎月の保険料 |
| 生命保険料控除 | 対象外 | あり |

- 保障額の動きのグラフ（団信＝ローンの残りの線、生命保険＝一定の点線）
- がん団信・3大疾病付き・ワイド団信は金利上乗せの目安（+0.1／+0.2／+0.3%）で、毎月・総額いくら増えるかを表示（`DANSHIN_OPTIONS`。金融機関・商品で違うので確認）
- 返している間に生命保険を減らす額（入力「団信で減らせる分」）を入れると、見直し額を表示
- 提案書3ページ目にも1行で入る

## ⑥ 区切り：まず「できるか」→ その土台で「やるか」
説明は ⓪〜⑧ の9ステップ。⑤もしも の次に **⑥ まず「できるか」を確かめる（区切り）** を入れ、⑦まとめ（やる・やらない）、⑧「今はいい」と続きます。

- 住宅ローンは、借りたい人や私たちではなく **融資する金融機関が決める**。当社で審査を申し込んだ方のうち、通るのは **10人中2〜3人ほど（目安）**（`PASS_RATE`。年・地域・金融機関で変わる）
- だから、やるか・やらないかを決める前に、まず「できるか」をこちらで確認する → その土台に乗ったら、通った金額の範囲で決めてもらう（できるかわからないまま決めても意味がなく、お客様の時間を無駄にしないための順番）
- 画面：10人の人型（2〜3人が金色）、①できるか（事前審査・無料・購入の義務なし）→ ②やるか・やらないか、数字で見る目安（返済比率・年収の何倍・完済年齢・定年後の返済、○／△見直し）と判定、金融機関が見ること（勤続・他の借入・信用情報・団信・担保評価）。通らなかったときの道（整えて時期を改める／賃貸のまま準備）も示す
- 提案書4ページ目の先頭とトップのおすすめアクションにも入る（`gate(x)`）
- **⓪ CIC取得**：事前審査の前に、お客様自身が CIC で信用情報を取り寄せる（本人開示：インターネット 500円・その場でPDF／郵送 1,500円・約10日。窓口は終了。`CIC` に1か所で定義し、手数料・方法は変わることがあるので公式 https://www.cic.co.jp/mydata/ で確認）。返済の遅れ・他の借入・最近の申し込みを先に自分で確かめる。⑥の画面（⓪→①→②）・提案書の次の一歩の先頭・トップのミッションに入る

## 2人暮らしの家賃「なし」
「2人暮らし」の欄で「なし（ひとり暮らしと同じ）」を選べます。結婚後（子育て期の前）も、ひとり暮らしの家賃のまま計算します（団信のときに家族が払い続ける家賃も同じ）。

## 定年・再雇用とローンの回数
- 初期値は **60歳で定年 → 65歳まで再雇用（年収は定年前の6割と仮定）→ 65歳から年金**。「あなたのこと」の欄で定年の年齢・再雇用の割合を変えられます。
- 生涯の給料・厚生年金は、再雇用の5年を下がった年収で計算します。
- ローンは **月で数えます（35年＝420回払い）**。③と提案書に「60歳の時点で360回払って残り60回（残高）」「再雇用の間の返済は年収の何%」「何歳で完済」を出します。35%を超えるときは、繰上げ返済・退職金で残りを減らす計画も一緒に考える、と添えます。

## トップページ（LIFE ROUTE）（お客様が主人公）
開くと最初に出る画面です（共有リンクで ステップ・画面共有 の指定があるときはそのステップから）。

- 主人公＝お客様：右上でお名前を入れると「◯◯ 様」。地図の道の上に後ろ姿と名前の旗。会社名は「提案書」欄の会社名（初期値は合同会社ジャパンマネジメント、`DEFAULT_COMPANY`）
- 地図の5つのエリア（現預金・NISA・保険・不動産・ライフプラン）に、その人の数字と「Lv.」。押すと説明のステップへ
- Lv.＝1＋できたミッションの数。ミッションは自動判定（NISAの積立・家賃6か月分の貯金・このシミュレーション）とチェック（事前審査〈無料・購入の義務なし〉・物件を見る・保険の見直し・ねんきんネット）
- 右側：今の資産（不動産／NISA／預貯金の割合）と65歳までの見通し、人生の目標（65歳までに準備したいお金に対して今いくら）、ライフイベント（今・社宅を出る・結婚・子ども・家を買う・定年・年金・完済）
- おすすめのアクション4つ、「次のステージへ」で ⓪ から説明開始。左のメニューから各ステップ・提案書・画面共有・条件の変更へ
- **映像と数字の連動**：地図の金色の道に、ライフイベントの印（27歳 今 → 30歳 家を買う → 60歳 定年 → 65歳 年金・完済）。印・右のグラフの点・ライフイベントの行のどれを押しても（指を乗せても）同じ年齢が一緒に光り、地図の左下に その年の数字（例：60歳 年収234万円・ローン残り60回・残高509万円、その年の資産）が出る。エリアのカードは大きな数字1つ＋何の数字か（`home().milestones`・`areas[].big`）。スマホでは道の印を省き、同じ数字を一覧と詳しい欄で見せる
- 数字はすべて `home(x, done, meta)`（`lib/engine.js`）から。見本の数字や根拠のない上昇率は出さない（テストで確認）。お名前とチェックは画面の中だけ（保存・共有しない）

## 賃貸の更新料と、審査が通りにくくなること
- **更新料**：2年ごとに家賃1か月分（欄で 0〜2か月・1〜3年ごとに変更可、社宅の間は0）。②の表に「更新料（2年ごとに1か月分・34回）197万円」と別の行で出し、提案書にも入れる（`x.renew`）。
- **老後の賃貸の入居審査**：65歳からは収入が年金だけ。家賃÷年金を出し、一般的な目安（収入の3分の1以内）を超えると「通りにくくなる場合があります」（⑤のカード・提案書③、`x.screening.rent`）。
- **住宅ローンの審査**：⑦の表に、待った場合の返済比率（毎月の返済×12÷その年の年収、目安 年収400万円未満30%・以上35%）を出し、年齢が上がると期間が短くなる・団信に入れない場合があることを添える（`wait[].screen`）。
- どれも「目安」「場合があります」で、断定しない（実際の審査は金融機関・管理会社ごとに違う）。

## 独身向けが初期値

商談のお客様の大半は独身（結婚願望「無し・あまり無し」71%）なので、**初期値は「独身・賃貸（家賃は平均）」**です。左上の「お客様のタイプ」で3つを切り替えられます（`preset("single" | "shataku" | "family")`）。

| タイプ | 家賃 |
|---|---|
| 独身・賃貸（家賃は平均） | ひとり暮らし 5.8万円＝当社のお客様の家賃の中央値（`RENT_AVG`） |
| 独身・社宅（30歳ごろまで） | 30歳までは自己負担 2万円（更新料なし）→ 社宅を出たら 5.8万円。買う年齢の初期値は社宅を出る30歳 |
| 結婚・子どもあり | 30歳で結婚・32歳で第1子。家賃は ひとり→2人→子育て→老後 |

社宅の自己負担・出る年齢は「社宅（会社の寮・借り上げ社宅）」の欄で変えられます（会社の規定に合わせる）。社宅の人には①で「社宅を出ると毎月いくら・年いくら家賃が上がるか」を数字で見せます。

独身のときは説明も変わります：
- ① ひとりで暮らしていく場合も家賃は一生続く。持ち家なら、結婚しても住み続ける・貸す・売るを選べる
- ③ ひとり分の年金から家賃を払い続ける
- ⑤ いちばんの心配は「年を取ってからの住まい」（高齢のひとり暮らしは入居を断られることがある）。団信で万一のときもローンが親や兄弟に残らない（「家族に住まいが残る」という家族向けの話はしない）
- 住宅ローン控除は一般の限度額（上乗せなし）

※独身・家賃が安めの場合、⑥の「差額を運用した場合」が持ち家の価値を上回ることもあります。その結果もそのまま見せます（公平な比較）。

各ステップに「話すこと（say）・見せる数字（show）・聞くこと（ask）」があり、営業が変わっても同じ説明になります（`lib/engine.js` の `talk()`）。

## 入力（すべて ▼ から選ぶ）
年齢・年収・貯金／結婚する年齢・子ども・パートナーの年収／暮らしの段階ごとの家賃（地域の目安）・家財保険／買う年齢・物件価格・金利・返済年数・**住宅の種類（住宅ローン控除）・固定資産税・火災地震保険**／**生命保険と団信で見直せる分**／老後の生活費。初期値は #03_商談報告 の中央値に近いお客様像（27歳・年収390万・貯金140万）。

## 計算の前提（画面の下にも表示）
- 年金：基礎年金を満額（令和8年度 847,300円）＋厚生年金「年収÷12（上限65万）× 5.481/1000 × 加入月数」の概算。ねんきんネットで確かめる。
- 賃貸：家賃×12＋更新料（2年ごとに1か月）。持ち家：返済＋固定資産税・保険・修繕（20年目から1.5倍）。諸費用はローンに含める設定。
- 家の価値：土地 年−1%／0%／＋1%、建物は30年で1割まで。**将来の価格は約束しない。**
- 税金：固定資産税・都市計画税（毎年・入力）。取得時の税金（不動産取得税・登録免許税・印紙税）は諸費用（物件価格の7%と仮定）に含む。
- 住宅ローン控除（2026〜2027年入居の制度）：住宅の種類ごとの限度額・期間（中古・買取再販その他 2,000万円・10年、ZEH 3,500万円・13年 など）。結婚後（40歳未満）や子育て中の入居で限度額が上がる住宅は上乗せ。年末残高×0.7% を、**給与から概算した所得税→住民税（課税所得×5%・最高97,500円）の範囲で**戻す（控除しきれない額は数えない）。「制度上の上限」と「戻る見込み」を分けて表示。
- 保険：賃貸は家財保険、持ち家は火災・地震保険（毎年）。生命保険は住まいとは別に表示し、団信で見直す分を設定したときだけ持ち家側を減らす。
- 公平な比較：賃貸の人が持ち家との差額を積み立てて年3%で運用できた場合も出す（元本保証なし）。
