# 設計：住まいの一生シミュレーター

## 1. 背景（#03_商談報告 から）
2026年10月下旬の #03_商談報告 16件をツール（`hearing-risk-analyzer`）で機械的に集計した（個人名は扱わず、件数と分布だけ）。
- 年齢の中央値 27歳（24〜46歳）、年収の中央値 約390万円、家賃の中央値 3万円（実家・低家賃が多い）、貯金の中央値 140万円
- 多いリスク：貯金が少ない（10件）、商談の長期化（9件）、異動・転勤（7件）、車のローン（5件）。結婚に触れた報告 10件
- **老後・年金に触れた報告は1〜2件だけ** → お客様も営業も「持たない場合の老後の住まい」を話していない

お客様ごとに説明がばらつき、「今の家賃と毎月の返済」の比較で終わってしまう。**一生（特に老後30年）の住まいのお金**を、誰にでも同じ順番で見せる型が必要。

## 2. 方針
1. **同じ物差しで2つの道を並べる**：賃貸のまま／持ち家 を、今から95歳まで1年ずつ計算。どちらかを悪く見せない。
2. **持たない場合の「準備」を数字にする**：老後の家賃を年金から払い続ける不足額と、65歳までに必要な積立額。脅すのではなく「知ったうえで選ぶ」。
3. **公平な比較も出す**：差額を運用した場合の額（元本保証なし）。持ち家の家の価値は3シナリオ。
4. **説明の型を固定**：①〜⑥の各ステップに「話すこと・見せる数字・聞くこと」。
5. **入力は選ぶだけ**：お客様の前で迷わない。

## 3. 計算（`lib/engine.js`）
- 暮らしの段階：結婚年齢・子どもの誕生年齢から ひとり／2人／子育て（22年間）／老後（65歳〜）を決め、段階ごとの家賃を使う。
- 持ち家：買う年齢まで賃貸と同じ。購入時に諸費用（ローンに含める設定なら0）、返済年数のあいだ返済、毎年 固定資産税・保険・修繕（20年目から1.5倍）。
- 老後：年金（本人＋配偶者の基礎年金 or 厚生年金）と、生活費＋住居費 の差の不足額を合計。
- 準備：老後の不足額の合計 ÷ 65歳までの月数。
- もしも：団信（残りのローン0）／賃貸なら家族の家賃が続く／金利＋1%の返済額。

## 4. テスト（`npm test`）
返済額、年金の上限、暮らしの段階ごとの家賃、完済後の費用、老後の不足（賃貸＞持ち家）と準備額、一生の住居費と家の価値の大小、団信と金利上昇、公平な比較、結婚しない場合、6ステップの中身、禁止表現。

**正確さの確認（`test/accuracy.test.js`）**：式とは別の方法で計算した答えと突き合わせる。
- ローン：月ごとに残高を追いかけて、完済時に0・各年末の残高が一致。3,000万円・1%・35年＝84,686円。
- 税金：年収390万の手計算（所得268万・課税所得105.5万・所得税52,750円・住民税164,000円）、最低保障74万円・基礎控除104万／67万／62万（令和8年分、財務省「令和8年度税制改正の大綱」）。
- 年金：年収390万・22〜65歳＝847,300＋919,164円。
- 住宅ローン控除：年ごとに 残高×住宅の割合・限度額・物件価格・0.7%・所得税・住民税（課税所得×5%・97,500円）を一つずつ当てはめた額と一致。上乗せは買う年に19歳未満の子がいる（または結婚していて40歳未満）ときだけ。95歳を過ぎた年は数えない。
- 内訳：95歳までに返し終わらない場合も 元金＝借りた額−残り。団信で見直せる生命保険は、65歳までのうち返している年数だけ。
- 324通りのお客様像で、内訳の合計＝一生の住居費、元金＝借りた額、控除≦払った税金、待つ間の家賃、老後の不足が食い違わない。
