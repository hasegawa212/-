# 設計：LIFE ROUTE（ライフルート、旧 住まいの一生シミュレーター）

## 1. 背景（#03_商談報告 から）
2026年10月下旬の #03_商談報告 16件をツール（`hearing-risk-analyzer`）で機械的に集計した（個人名は扱わず、件数と分布だけ）。
- 年齢の中央値 27歳（24〜46歳）、年収の中央値 約390万円、家賃の中央値 3万円（実家・低家賃が多い）、貯金の中央値 140万円
- 多いリスク：貯金が少ない（10件）、商談の長期化（9件）、異動・転勤（7件）、車のローン（5件）。結婚に触れた報告 10件
- **老後・年金に触れた報告は1〜2件だけ** → お客様も営業も「持たない場合の老後の住まい」を話していない

お客様ごとに説明がばらつき、「今の家賃と毎月の返済」の比較で終わってしまう。**一生（特に老後30年）の住まいのお金**を、誰にでも同じ順番で見せる型が必要。

## 2. 方針
1. **同じ物差しで2つの道を並べる**：賃貸のまま／持ち家 を、今から95歳まで1年ずつ計算。どちらかを悪く見せない。
2. **持たない場合の「準備」を数字にする**：老後の家賃を年金から払い続ける不足額と、65歳までに必要な積立額。脅すのではなく「知ったうえで選ぶ」。
3. **公平な比較も出す**：差額を運用した場合の額（元本保証なし）。持ち家の家の価値は3シナリオ。
4. **説明の型を固定**：①〜⑥の各ステップに「話すこと・見せる数字・聞くこと」。
5. **入力は選ぶだけ**：お客様の前で迷わない。

## 3. 計算（`lib/engine.js`）
- 暮らしの段階：結婚年齢・子どもの誕生年齢から ひとり／2人／子育て（22年間）／老後（65歳〜）を決め、段階ごとの家賃を使う。
- 持ち家：買う年齢まで賃貸と同じ。購入時に諸費用（ローンに含める設定なら0）、返済年数のあいだ返済、毎年 固定資産税・保険・修繕（20年目から1.5倍）。
- 老後：年金（本人＋配偶者の基礎年金 or 厚生年金）と、生活費＋住居費 の差の不足額を合計。
- 準備：老後の不足額の合計 ÷ 65歳までの月数。
- もしも：団信（残りのローン0）／賃貸なら家族の家賃が続く／金利＋1%の返済額。

## 4. テスト（`npm test`）
返済額、年金の上限、暮らしの段階ごとの家賃、完済後の費用、老後の不足（賃貸＞持ち家）と準備額、一生の住居費と家の価値の大小、団信と金利上昇、公平な比較、結婚しない場合、6ステップの中身、禁止表現。

**正確さの確認（`test/accuracy.test.js`）**：式とは別の方法で計算した答えと突き合わせる。
- ローン：月ごとに残高を追いかけて、完済時に0・各年末の残高が一致。3,000万円・1%・35年＝84,686円。
- 税金：年収390万の手計算（所得268万・課税所得105.5万・所得税52,750円・住民税164,000円）、最低保障74万円・基礎控除104万／67万／62万（令和8年分、財務省「令和8年度税制改正の大綱」）。
- 年金：年収390万・22〜65歳＝847,300＋919,164円。
- 住宅ローン控除：年ごとに 残高×住宅の割合・限度額・物件価格・0.7%・所得税・住民税（課税所得×5%・97,500円）を一つずつ当てはめた額と一致。上乗せは買う年に19歳未満の子がいる（または結婚していて40歳未満）ときだけ。95歳を過ぎた年は数えない。
- 内訳：95歳までに返し終わらない場合も 元金＝借りた額−残り。団信で見直せる生命保険は、65歳までのうち返している年数だけ。
- 324通りのお客様像で、内訳の合計＝一生の住居費、元金＝借りた額、控除≦払った税金、待つ間の家賃、老後の不足が食い違わない。

## 社宅と家賃平均（2026年10月追加）
- 家賃の初期値はひとり暮らし 5.8万円＝当社のお客様（20代後半・単身・賃貸）の家賃の中央値（`RENT_AVG`、#02 見込み報告の集計）。
- 社宅：`shataku: { on, self, until }`。`until` 歳になる前は家賃＝自己負担（初期値 2万円、商談で多い1〜3万円の中央）・更新料なし・段階は「社宅」。`until`（初期値30歳、規定で変わる）からはふつうの家賃。
- 社宅の人は社宅を出る年齢で買う計画が初期値。①で「社宅を出ると毎月＋3.8万円・年＋45.6万円」を見せる。社宅の間は貯金と準備の時期、と伝える（あおらない）。
- テスト：`test/shataku.test.js`（8件）。

## 定年・再雇用とローンの回数（2026年10月追加）
- `reemploy: { age: 60, rate: 0.6 }`：定年から `retireAge`（65）までの年収＝定年前×rate（昇給なし）。`pension(income, workStart, retireAge, reemploy)` の厚生年金も、その5年は下がった月給×5.481/1000×月数。
- `loan.months`（35年＝420）、`loan.atReemploy` / `loan.atRetire`（払った回数・残り回数・残高）、`loan.ratioNow` / `loan.ratioReemploy`（毎月の返済×12÷年収、再雇用は今の年収×rate で控えめに）。
- 文は `workLoanLine(x)` で一つにして、③と提案書③で同じ文を使う。返済比率 35% 超は繰上げ返済・退職金の計画を添える。
- テスト：`test/reemploy.test.js`（8件。年収390万の手計算：給料 12,870万＋1,170万、厚生年金 325,000×5.481/1000×456＋195,000×5.481/1000×60）。

## トップページ（LIFE ROUTE）（2026年10月追加）
- お客様が主人公のゲーム風トップ。`home(x, done, meta)` が hero（名前・会社・Lv）、assets（今の資産と内訳・今〜65歳の見通し path：預貯金＋NISA＋家の価値−残り。65歳は portfolio.at65 と一致）、goal（65歳までに準備したいお金に対する今の資産の割合）、areas（5エリア・数字・Lv・進み具合・押したときのステップ）、missions（自動／チェック）、events（年齢順）、actions（4つ）を返す。画面は描くだけ。
- 地図の絵・主人公の後ろ姿は手描きSVG（外部画像なし・1ファイルのまま）。スマホでは地図のカードを2列に並べ、地図を先頭に。
- あおらない：上昇率・見本の数字は出さない、事前審査は「無料・購入の義務はありません」（`test/home.test.js` 8件）。

## 映像と数字の連動（2026年10月追加）
- `home().events[].stat`：出来事ごとの数字（買う＝毎月の返済×回数、定年＝再雇用の年収とローンの残り回数・残高、年金＝毎月の年金、社宅を出る＝家賃がいくら上がるか）。
- `home().milestones`：道の印。今（t=0）〜GOAL（65歳、t=1）、t＝年齢の比率。同じ年齢はまとめ、65歳より後（完済が70歳など）はGOALの印に年齢つきで入れる。assets＝その年の資産（グラフの点と同じ値）。
- 画面：印は道（SVG path）の上に getPointAtLength で置く（年齢の比率と等間隔をまぜて重ならないように。順番は変えない）。印・グラフの点・一覧の行は同じ data-age を持ち、どれを選んでも一緒に光って詳しい欄に数字が出る。
- エリアのカードは `big`（大きな数字1つ）＋`bigLabel`。カードは地図の左右の端、道は真ん中を通す。
- テスト：`test/home-link.test.js`（5件）。

## 団信と生命保険（2026年10月追加）
- `danshin(x)`：cover（年ごとの保障額＝ローンの残り、完済で0）・general（一般団信は金利に含まれ別払いなし）・options（`DANSHIN_OPTIONS` がん+0.1%／3大疾病+0.2%／ワイド+0.3%の目安 → payment の差で毎月・総額）・life（毎月・65歳までの総額・保障額 `lifeIns.cover`）・review（団信で減らせる分×返している年数）・rows（くらべる表）・message（独身／家族）。

## 親御さまの反対（バブル崩壊のイメージ）への切り返し（2026年10月追加）
- 「親に相談したら反対された」は、親御さまが1990年前後（バブル崩壊）の住宅ローンと値下がりを見てきたことが多い。否定せず「当時と条件が違う」ことを数字で見せる。
- `BUBBLE`（都市銀行の変動金利の最高 8.5%〔1990〜91年〕・住宅金融公庫 約5.5%）と `bubble(x)`（同じ借入額・年数を当時の金利で計算した毎月の返済と、今の計画の返済）。標準の例：2,996万円・35年 → 8.5%で22.4万円／5.5%で16.1万円／今の1.2%で8.7万円。
- ⑧の show と画面（waitView の右下）に1文。「値上がりをあてにせず、住むために払える範囲で考える」「値下がりもありうるので⑦の下落シナリオも一緒に」と必ずセット（値上がりを約束しない）。
- 商談の切り返しは hearing-risk-analyzer の `x_parentBubble`（親御さまとの同席30分を提案、本人の了承なく親に連絡しない）。
- テスト：`test/bubble.test.js`（3件）。あわせて⑧の表を横スクロールにして、スマホ幅（390px）で画面がはみ出さないようにし、⑥の問いかけを1行に収めて画面共有の1280×720に収まるようにした。
